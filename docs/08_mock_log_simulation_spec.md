# 📝 ダミー学習ログ生成 ＆ GNN-KTシミュレーション仕様書

本ドキュメントは、スタサプRAGエンジンの統合ベクトルデータベース（`global_vector_db_cache.json`）を基に、架空の生徒の学習履歴を生成する `generate_mock_logs.py` の仕様と、そこに含まれる「GNN-KT（Knowledge Tracing）」のシミュレーション・アルゴリズムについて定義します。

---

## 🌟 1. 目的と役割

本シミュレーターは、単なるランダムな正誤データを生成するものではありません。
生徒一人ひとりに「学習特性（ペルソナ）」を持たせ、さらにオントロジー（知識の繋がり）を利用した「連鎖エラー」を発生させることで、**極めて現実のクラスに近いリアルな躓きデータ**を構築します。

このデータは、以下の次世代機能の実証・UIテストに不可欠な基盤となります。
* **FT（教員向け）**: Semantic Zoom（階層型ヒートマップ）における、クラス全体の「真の躓き原因」の可視化テスト。
* **Learn（生徒向け）**: 適応型学習ナビにおける、忘却曲線と弱点推論に基づいた「遡り学習」のレコメンドテスト。

---

## 👥 2. クラス構成とペルソナ定義

1クラス（デフォルト40人）を生成する際、以下の5つのペルソナ（学習特性）を所定の出現ウェイト（確率）で生徒に割り当てます。これにより、平均化されたデータではなく、現実の教室に見られる「多様な得意・苦手」のコントラストを生み出します。

| ペルソナ名 | 出現割合 | 特徴とベース正答率の設定 |
| :--- | :---: | :--- |
| **知識・技能偏重型** | **30%** | コツコツ暗記タイプ。<br>・観点 `knowledge_skill` (基礎) = **85%**<br>・観点 `thinking_judgment` (応用) = **30%** |
| **思考力・判断力特化型** | **20%** | 地頭は良いが基礎抜けが多いタイプ。<br>・観点 `knowledge_skill` (基礎) = **50%**<br>・観点 `thinking_judgment` (応用) = **80%** |
| **分野特化の偏り型** | **20%** | 特定ドメイン（親概念）にアレルギーを持つタイプ。<br>・得意な分野 = **90%**<br>・苦手な分野 = **20%**<br>・その他の分野 = **50%** |
| **全体得意型** | **15%** | 優秀層。全体を通してベース正答率 **90%** 前後。 |
| **全体苦手型** | **15%** | 支援が必要な層。全体を通してベース正答率 **25%** 前後。 |

---

## 🔗 3. GNN-KT 連鎖ペナルティのアルゴリズム

ペルソナに基づく「ベース正答率」に対し、GNN-KT（グラフ構造）のコアとなる**「前提知識の依存関係によるペナルティ」**を乗算します。
生徒ごとに「各親概念（Level 3）を潜在的に理解しているか（Mastery State）」を初期判定し、未理解の概念に依存する問題を解く際に以下のペナルティを発動させます。

### ① 必須前提 (`mandatory`) が未理解の場合
* **ペナルティ**: ベース正答率 × **0.1**
* **シミュレーション意図**: 解法プロセスが破綻する決定的な前提知識であるため、「ここが抜けている生徒は、まぐれ当たり以外では応用問題を正解できない」という強い因果関係をグラフ上で表現します。

### ② 補足前提 (`supplementary`) が未理解の場合
* **ペナルティ**: ベース正答率 × **0.7**
* **シミュレーション意図**: 知っていると計算効率や理解がスムーズになる知識であるため、「ゴリ押しで解ける可能性は残るが、ミス（計算間違いや時間切れ）を誘発しやすい状態」を表現します。

> **💡 Semantic Zoom への波及効果**
> このロジックにより、FTのダッシュボード上では「特定の応用問題（Level 4）の正答率が極端に低く赤色になっているが、ドリルダウンして前提知識（Level 3）を辿ると、クラスの半数がその基礎概念を落としていたことが真の原因だった」というストーリーが自動的に可視化されます。

## 📦 4. 出力データ構造 (`mock_student_logs.json`)

生成されるダミーログは、以下のJSONスキーマで出力されます。
解答時間（`time_taken_sec`）も、正解時は短く、不正解時は長く（悩んだ状態）なるよう自動シミュレーションされます。

```json
{
  "metadata": {
    "generated_at": "2026-08-04T12:00:00",
    "total_students": 40,
    "total_logs": 1200
  },
  "logs": [
    {
      "log_id": "8a3b2c1d-...",
      "student_id": "STU_A1B2C3D4",
      "persona": "knowledge_heavy",
      "question_number": "(1)",
      "aligned_concept": "分数が含まれる平方完成を処理する",
      "parent_concept": "平方完成",
      "competency": "knowledge_skill",
      "is_correct": false,
      "time_taken_sec": 145,
      "timestamp": "2026-07-25T14:30:00"
    }
  ]
}
```
