# 🎓 Learn（生徒向け）軸 次世代機能構想・詳細仕様書

## 🌟 1. 概要とコンセプト

本ドキュメントは、スタサプRAGエンジン（16桁コード＋独自枝番＋ベクトルDB）をベースとした、**生徒用学習画面（Learn）**における次世代機能構想をまとめた仕様書です。

Learn軸のコンセプトは、**「自律的学習（Self-Regulated Learning）の圧倒的サポート」**です。膨大な動画や問題の中から「今、自分は何をすべきか」「どこで躓いているのか」「次にどう繋がるのか」をAIが提示し、生徒が迷わず学習に没頭できる「AIパーソナルチューター」としての体験を提供します。

## 🔍 3. 各機能の詳細仕様とLearn活用イメージ

### 3.1 対話型 / マルチモーダル AIチューター

#### 📝 機能内容
生徒が自学自習中に分からない問題に直面した際、チャットで質問したり、スマホで問題の写真を撮ってアップロードしたりすると、AIが直接「答え」を教えるのではなく、**「ヒントとなる解説動画の秒数」と「類似の確認問題」を提示する機能**です。現在、テキスト・画像入力によるハイブリッド検索UI（`app.py`）が稼働しています。

#### 🧠 Graph RAG連動による「遡り学習」の支援
バックエンドで「Graph RAG（ネットワーク探索）」が稼働しているため、解けない問題に対して単にその解説動画を出すだけでなく、オントロジーの繋がりを利用して**「躓きの原因となっている可能性が高い『前提知識（親概念）』の復習動画」**まで自動提示し、根本的な理解不足を解消します。

#### 🎁 生徒への提供価値
* **24時間即時解決**: わからない問題で何十分もフリーズする時間がなくなり、学習のモチベーション低下を防ぎます。
* **「答え写し」の防止**: AIが答えを生成するのではなく、「この動画のここを見れば解けるよ」と自力で解決するルートを示すため、真の学力定着に繋がります。

#### 📱 Learn画面での活用イメージ
* 生徒: 「この宿題プリントの(3)がわかりません（画像を送信）」
* 🤖 AI: 「ここは【おき換えを利用した因数分解】(`_033`)が鍵になるね！まずはこの動画の `01:15`〜 を見てみよう。もし『おき換え』自体がピンとこない場合は、**前提となる【共通因数でくくる】の動画（第1講 PART2）**も一緒に復習すると完璧だよ！」

---

### 3.2 適応型学習ナビ（Adaptive Journey）

#### 📝 機能内容
生徒の過去の正誤データや、先生（FT）が設定したシラバス・テスト範囲をもとに、**「今日、どの動画のどの部分を見て、どの問題を解くべきか」をレコメンドする機能**です。

#### 🎯 GNN-KT ＋ Semantic Zoom と連動した超高精度レコメンド
FT側の「GNN-KT（真の理解度推論）」と完全にデータ連携することで、「今日のミッション」は単なる正答率ベースではなく、**オントロジー上の潜在的な弱点（例：係数が分数の場合の平方完成の理解不足）に基づいて生成**されます。グラフ構造（`mandatory` / `supplementary` の依存重み）を利用した精緻な予測により、忘却曲線に合わせた最適な復習が自動で組み込まれます。

#### 🎁 生徒への提供価値
* **迷子ゼロの学習体験**: 膨大な講座一覧から自分で動画を探す手間がなくなり、ログインしてすぐに「今日のミッション（最適化されたプレイリスト）」に取り組めます。

#### 📱 Learn画面での活用イメージ
* **ダッシュボード「今日のミッション」**:
  * 🔴 **【復習】** 昨日間違えた「特定文字に着目した次数」 ➔ 復習用類題 1問
  * 🔵 **【本日の授業】** シラバスに基づく「因数分解の公式」 ➔ 解説動画（00:00〜05:30）＋ 確認問題 2問
  * 🟡 **【FTより】** 先生からの配信課題 ➔ テスト対策セット

---

### 3.3 スキルツリー可視化（学習オントロジーのゲーミフィケーション）

#### 📝 機能内容
抽出された概念の繋がり（ネットワーク）を、生徒向けにわかりやすく**「スキルツリー」として可視化・ゲーミフィケーション化する機能**です。現在、`app.py` 上で `streamlit-agraph` を用いて、必須前提（実線）と補足前提（点線）を視覚的に分離した描画が実装されています。

#### 🎁 生徒への提供価値
* **学習の現在地と目的の理解**: 「いま学んでいる公式が、次のどの単元（ボス）を倒すために必要なのか」が視覚的にわかり、学習意欲（主体性）が向上します。
* **成長の可視化**: 枝番概念をマスターするごとにツリーのノードが点灯し、レベルアップしていく達成感を得られます。GNN-KTによる「真の理解度」が一定値を超えた際にノードが輝くといった動的演出への拡張を予定しています。

#### 📱 Learn画面での活用イメージ
* **学習マップ（スキルツリー）画面**:
  * 「知識・技能」の基礎ノード（赤色）をクリアすると、上位の「思考力・判断力等」の応用ノード（青色）への道がアンロックされるアニメーション。
  * 自分がどこまで進んでいるか、どの概念が未習得（暗いまま）かが一目でわかるマップUI。

## 🤝 4. FT（教員向け）と Learn（生徒向け）の連携シナリオ

Learn軸の真の力は、FT軸とデータが連動（16桁コード＋枝番で同期）することで発揮されます。

1. **生徒（Learn）**が「AIチューター」で特定の枝番概念について何度も質問する、あるいは問題を解く。
2. そのログが**GNN-KTエンジン**に流し込まれ、**先生（FT）**の「Semantic Zoomダッシュボード」にクラスの真の理解度として動的に反映・アラートが上がる。
3. **先生（FT）**が授業でその概念をフォローしたり、ピンポイントな公式類題プレイリストを配信したりする。
4. **生徒（Learn）**の「今日のミッション」にその補習プレイリストが届く。
