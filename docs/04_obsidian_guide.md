# 🎨 Obsidian ナレッジグラフ設定ガイド

本ドキュメントでは、スタサプRAGエンジンで構築されたナレッジグラフを Obsidian（ナレッジ管理ツール）で可視化・分析するための設定手順について解説します。

---

## 📦 Vault パッケージの出力

バックエンドで以下のスクリプトを実行することで、全単元のオントロジーノード、問題ノード（大問・確認問題）、動画セグメントノード、およびGNN-KT対応の重み付き前提知識が相互にリンクされた Obsidian Vault パッケージ（ZIP）が自動生成されます。

```bash
python export_global_obsidian_vault_mext.py
# 成果物: Global_Obsidian_Vault_MEXT.zip
```

解凍したフォルダーを Obsidian の「Open folder as vault（既存のフォルダーをVaultとして開く）」から読み込むことで、ナレッジグラフがそのまま利用可能になります。

## 🎨 Graph View 推奨色分け設定 (Groups)

Obsidian の **Graph View（グラフビュー）** を開き、右上の設定（歯車アイコン）➔ **Groups（グループ）** に以下のタグ検索クエリを追加して色を設定します。
フロントエンドのAIチューターUIと色調を統一することで、「知識群（グループ）」の変容プロセスが鮮やかに可視化されます。

| 階層 / ノード種別 | 検索クエリ (Obsidian) | 目的・意味合い | 推奨カラー案 |
| :--- | :--- | :--- | :--- |
| **基礎知識** | `tag:#node/foundation_knowledge` | 単元のベースとなる純粋な数学的定義・用語 | 🟦 青 / ライトブルー |
| **視点・条件** | `tag:#node/perspective_condition` | 事象を捉え直す枠組み（思考のレンズ） | 🟪 紫 / パープル |
| **再構成知識** | `tag:#node/derived_knowledge` | 基礎知識に視点を通した結果の新たな気付き | 🟩 緑 / グリーン |
| **タスク (アクション)** | `tag:#node/tasks` | 生徒が実際に行う処理手順（GNN-KT推論対象） | ⬛ 紺 / ダークグレー |
| **大問 (モデリング)** | `tag:#node/exercise` | 先生が解法を見せるための代表的な問題データ | 📘 濃い青 / ネイビー |
| **確認問題 (アセスメント)** | `tag:#node/question` | 生徒が自力で解く演習用の問題データ | ⚪ 白 / ライトグレー |
| **講義動画** | `tag:#node/video` | ピンポイント解説動画セグメント | 🟡 黄 / ゴールド |
| **講義ハブ** | `tag:#node/lecture_name` | 特定の講義に属するすべての要素を束ねるハブ | ⭐️ 星 / 明るい黄色 |

## 💡 視覚化の最適化とノードの読み方

### 1. タスク難易度と「知識群」の把握 (GNN-KT連携)
Graph View の表示設定（Display）にて **「Arrows（矢印）」を ON** に設定してください。
タスクノード（⬛ 紺）に向かって引かれている前提知識（`prerequisite`）の矢印の出どころを確認することで、タスクの難易度（認知負荷）を直感的に判別できます。
*   **基本技能**: 基礎知識（🟦 青）から直接矢印が引かれているタスク（単純適用）。
*   **高度な技能**: 再構成知識（🟩 緑）から矢印が引かれているタスク（視点の切り替えと論理的判断を伴う高難易度タスク）。

### 2. スマートリンクと逆引きリスト (下位概念)
各概念ノードを開くと、下部に **「🔽 属する知識・タスク (下位概念)」** というリストが自動生成されています。これにより、ある親概念から派生するミクロな躓きポイント（タスク）を一覧で把握できます。
システムの「エンティティ統合」により、親概念の名前と一致する実体ノードが存在する場合は、重複するダミーハブは生成されず、すべて実体ノードに美しくリンクが収束します。

### 3. リッチ化された講義動画ノードと主従関係
動画ノード（`【動画】...`）を開くと、単なるファイル情報だけでなく、**「🏛️ 所属単元」「🧠 関連する知識・タスク（インプット講義）」** そして **「📝 紐付けられた大問・確認問題」** が表示されます。
特に問題については、その動画が問題を直接解説している「メイン教材」なのか、別の問題を解くための「前提・復習」として扱われているのかが視覚的に分離されて表示されるため、カリキュラムにおける教育的役割の逆引き分析が容易です。

### 4. 解説要約の優先表示 (Explainable AI)
Obsidianの各種ノードに紐づく動画リストには、板書OCR（数式の羅列）ではなく、先生のティーチング意図を言語化した **「💬 解説要約」** が表示されます。AIチューターがなぜこの動画をサジェストしたのかという理由（Explainable AI）を、人間が直感的に確認できるよう最適化されています。
