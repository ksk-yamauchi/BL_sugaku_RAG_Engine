# 🎨 Obsidian ナレッジグラフ設定ガイド

本ドキュメントでは、スタサプRAGエンジンで構築されたナレッジグラフを Obsidian（ナレッジ管理ツール）で可視化・分析するための設定手順について解説します。

---

## 📦 Vault パッケージの出力

バックエンドで以下のスクリプトを実行することで、全単元のオントロジーノード、問題ノード、動画セグメントノード、およびGNN-KT対応の重み付き前提知識が相互にリンクされた Obsidian Vault パッケージ（ZIP）が自動生成されます。

```bash
python export_global_obsidian_vault_mext.py
# 成果物: Global_Obsidian_Vault_MEXT.zip
```

解凍したフォルダーを Obsidian の「Open folder as vault（既存のフォルダーをVaultとして開く）」から読み込むことで、ナレッジグラフがそのまま利用可能になります。

---

## 🎨 Graph View 推奨色分け設定 (Groups)

Obsidian の **Graph View（グラフビュー）** を開き、右上の設定（歯車アイコン）➔ **Groups（グループ）** に以下のタグ検索クエリを追加して色を設定することで、教育オントロジーおよび学習観点の構造が鮮やかに可視化されます。

| 階層 / ノード種別 | 検索クエリ (Obsidian) | 目的・意味合い | 推奨カラー案 |
| :--- | :--- | :--- | :--- |
| **知識・概念** | `tag:#node/foundation_knowledge` | 単元のベースとなる純粋な数学的定義・用語 | 🟠 オレンジ |
| **視点・条件** | `tag:#node/perspective_condition` | 事象を捉え直す枠組み（思考のレンズ） | 🟤 ブラウン / イエロー |
| **タスク (アクション)** | `tag:#node/tasks` | 生徒が実際に行う処理手順（GNN-KT推論対象） | 🟣 紫 / マゼンタ |
| **確認問題** | `tag:#node/question` | 演習用の個別の問題データ | ⚪ 白 / ライトグレー |
| **講義動画** | `tag:#node/video` | ピンポイント解説動画セグメント | 🟢 エメラルドグリーン |

## 💡 視覚化の最適化とノードの読み方

1. **スマートリンクと逆引きリスト (下位概念)**:
   * 各概念ノードを開くと、下部に **「🔽 属する知識・タスク (下位概念)」** というリストが自動生成されています。これにより、ある親概念から派生するミクロな躓きポイント（タスク）を一覧で把握できます。
   * システムの「エンティティ統合」により、親概念の名前と一致する実体ノードが存在する場合は、重複するダミーハブは生成されず、すべて実体ノードに美しくリンクが収束します。

2. **リッチ化された講義動画ノード**:
   * 動画ノード（`【動画】...`）を開くと、単なるファイル情報だけでなく、**「🏛️ 所属単元」「🧠 関連する知識・タスク（インプット講義）」「📝 紐付けられた確認問題（直接解説 / 前提概念）」** が細かく分類されて表示されます。これにより、その動画がカリキュラムの中でどのような教育的役割を担っているか逆引き分析が可能です。

3. **解説要約の優先表示**:
   * Obsidianの各種ノードに紐づく動画リストには、板書OCR（数式の羅列）ではなく、先生のティーチング意図を言語化した **「💬 解説要約」** が表示されます。AIチューターがなぜこの動画をサジェストしたのかという理由（Explainable AI）を、人間が直感的に確認できるよう最適化されています。

4. **指向性（矢印）の表示**:
   * Graph View の表示設定（Display）にて **「Arrows（矢印）」を ON** に設定してください。前提知識の依存関係（どの概念がどの概念の前提になっているか）が一目で把握できるようになります。
