# 🎨 Obsidian ナレッジグラフ設定ガイド

本ドキュメントでは、スタサプRAGエンジンで構築されたナレッジグラフを Obsidian（ナレッジ管理ツール）で可視化・分析するための設定手順について解説します。

---

## 📦 Vault パッケージの出力

バックエンドで以下のスクリプトを実行することで、全単元のオントロジーノード、問題ノード、動画セグメントノード、およびGNN-KT対応の重み付き前提知識が相互にリンクされた Obsidian Vault パッケージ（ZIP）が自動生成されます。

```bash
python export_global_obsidian_vault_mext.py
# 成果物: Global_Obsidian_Vault_MEXT.zip (Ver 12.0 対応)
```

解凍したフォルダーを Obsidian の「Open folder as vault（既存のフォルダーをVaultとして開く）」から読み込むことで、ナレッジグラフがそのまま利用可能になります。

---

## 🎨 Graph View 推奨色分け設定 (Groups)

Obsidian の **Graph View（グラフビュー）** を開き、右上の設定（歯車アイコン）➔ **Groups（グループ）** に以下のタグ検索クエリを追加して色を設定することで、教育オントロジーおよび学習観点の構造が鮮やかに可視化されます。

| 階層 / ノード種別 | 検索クエリ (Obsidian) | 目的・意味合い | 推奨カラー案 |
| :--- | :--- | :--- | :--- |
| **Level 3 (親概念ハブ)** | `tag:#format/concept_level3` | 単元を跨ぐ学問的ハブ（例: 平方完成） | 🟠 オレンジ |
| **Level 4 (学習アクション)** | `tag:#format/concept_level4` | 生徒のミクロな処理手順・躓き（枝番） | 🟣 紫 / マゼンタ |
| **確認問題** | `tag:#format/question_item` | 演習用の個別の問題データ | ⚪ 白 / ライトグレー |
| **講義動画** | `tag:#format/video` | ピンポイント解説動画セグメント | 🟢 エメラルドグリーン |
| **観点: 知識・技能** | `tag:#Competency/知識・技能` | Semantic Zoom: 基礎的計算・定義 | 🔴 赤 |
| **観点: 思考・判断・表現** | `tag:#Competency/思考力・判断力等` | Semantic Zoom: 応用・立式・多面的考察 | 🔵 青 |

## 💡 視覚化の最適化テクニック

1. **指向性（矢印）の表示**:
   * Graph View の表示設定（Display）にて **「Arrows（矢印）」を ON** に設定してください。
   * 前提知識の依存関係（どの概念がどの概念の前提になっているか）や、親概念ハブから学習アクションへの階層性の向きが一目で把握できるようになります。

2. **前提知識ネットワークの可視化**:
   * 各概念ノート内の「➡️ 前提知識 (重み付きネットワーク)」セクションには、**🔵 必須前提知識（Mandatory）** と **🟡 補足前提知識（Supplementary）** が理由付きで識別表示されます。

3. **孤立ノードの非表示**:
   * Display 設定の **「Orphan nodes」を OFF** にすることで、リンク構造をよりシンプルかつ明確に整理できます。

4. **ノードサイズの自動強調**:
   * Display 設定の **「Node size」** の数値を上げると、多くのリンクを集める Level 3（親概念ハブ）が視覚的に大きく強調され、カリキュラムの重要ハブが明確になります。
