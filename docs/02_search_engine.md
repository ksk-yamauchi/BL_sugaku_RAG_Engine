# 🔍 AIチューター検索エンジンの仕組み (`app.py`)

本ドキュメントでは、フロントエンドアプリ（`app.py`）で採用されている検索アルゴリズム、ハイブリッド検索、スコアリング、およびGraph RAGを用いたネットワーク探索の仕組みについて解説します。

---

## 🛠️ 検索アルゴリズムの処理フロー

入力された自然言語（会話文）や画像から、意味的ドリフト（ノイズによる誤検索）を防ぎ、意図した概念・問題を確実にヒットさせ、さらにオントロジーの繋がりまで提示するパイプラインです。

│ 2. ベクトル類似度計算 (Dense Search)          │

                        │

│ 3. 意図判定によるベースライン微調整           │

## 🌟 主な機能と特徴

### 1. ゼロ・レイテンシのクエリサニタイズ (ノイズ除去)
画像検索から抽出されたテキストに含まれる小問番号（例: `(1)`, `[ア]`）や数式（LaTeXの `$...$`）を、API通信（LLM）を挟まずに正規表現で瞬時に除去します。これにより、記号がキーワードとして認識されるのを防ぎ、「関係のない問題が完全一致ブーストを受けて検索トップに躍り出る」という誤爆を完全に防止します。

### 2. 意図判定 ＋ 不要語除去のハイブリッド検索
ユーザーの入力フレーズ（例: 「教えて」「とは」 vs 「問題」「解き方」）を検知し、概念ルートと問題ルートのベーススコアを動的に加点調整します。また、会話ノイズを除去してコアキーワードを抽出し、ターゲットのテキストに完全一致した場合に最大 `+30.0%` のブーストを加算します。

### 3. Graph RAG による多次元学習ネットワークの構築
トップヒットした概念を中心に、ベクトル検索だけでは拾いきれない**「文脈の繋がり」**を提示します。
*   **⏪ 遡り学習 (Prerequisites)**: つまずきを解消するための前提知識ノード。
*   **⏩ 横展開 (Siblings)**: 同じ親概念に属する兄弟ノード。
*   **⏭️ 応用先 (Next Steps)**: 現在の概念を前提知識として利用する、次のステップのノード。

### 4. Explainable AI (XAI) と表示の最適化
UI上で学習者に動画をサジェストする際、単に「板書に書かれている数式の羅列（`blackboard_ocr`）」を見せるのではなく、**「先生がどういう意図でその解説を行っているか（`explanation_summary`）」**を前面に表示する設計としています。
ベクトルDBの裏側では数式（OCR）を利用して高精度な検索を行いつつ、フロントエンドでは「ティーチングの意図」を提示することで、生徒が「なぜこの動画を見るべきなのか」を納得して自律的に学習できる UX (ユーザー体験) を実現しています。




## （参考）旧仕様の主な機能と特徴（新機能への改修時に必要/不必要を判断）

### 1. ゼロ・レイテンシのクエリサニタイズ (ノイズ除去)
* **正規表現による高速処理**: 画像検索から抽出されたテキストに含まれる小問番号（例: `(1)`, `[ア]`）や数式（LaTeXの `$...$`）を、API通信（LLM）を挟まずに正規表現で瞬時に除去します。
* **Lexical Boostの誤爆防止**: 記号や数式がキーワードとして認識されるのを防ぐことで、「関係のない問題が完全一致ブースト（+30.0%）を受けて検索トップに躍り出る」という誤検索を完全に防止します。

### 2. 意図判定 ＋ 不要語除去のハイブリッド検索
* **意図判定ブースト**: ユーザーの入力フレーズ（例: 「教えて」「とは」 vs 「問題」「解き方」）を検知し、概念ルートと問題ルートのベーススコアを動的に加点調整します。
* **クエリ精製とLexical Boost**: 会話ノイズ（Stop Words）を除去してコアキーワードを抽出し、ターゲットのテキスト（`concept_name`, `parent_concept`, `summary` など）に完全一致した場合に最大 `+30.0%` のブーストを加算します。重複ヒットによるスコア崩壊を防ぐため、1ノードにつき一重加点のみに制限しています。

### 3. スコア可視化と上限クリッピング
* UI上に **「ベース類似度」「加点ブースト」「未習範囲減点」** の内訳を詳細に表示し、デバッグや検証を容易にしています。総合適合度は100%を上限としてクリッピング処理されます。

### 4. Graph RAG による多次元学習ネットワークの構築
* トップヒットした概念を中心に、ベクトル検索だけでは拾いきれない**「文脈の繋がり」**を提示します。
  * **⏪ 遡り学習 (Prerequisites)**: つまずきを解消するための前提知識ノード。
  * **⏩ 横展開 (Siblings)**: 同じ親概念に属する兄弟ノード。
  * **⏭️ 応用先 (Next Steps)**: 現在の概念を前提知識として利用する、次のステップのノード。
* ベクトル検索の次点リスト（`runner_ups`）とGraph RAGの提示ノードが重複した場合、次点リスト側から該当ノードを除外（重複排除）し、UIを洗練させています。
