# PART5 $90^\circ - \theta$ の三角比

## 要点① $90^\circ - \theta$ の三角比

右の図の直角三角形において、$\angle \text{A} = \theta$ とすると

$$\sin\theta = \frac{a}{c}, \quad \cos\theta = \frac{b}{c}, \quad \tan\theta = \frac{a}{b}$$

[図の説明: 頂点Cが直角の直角三角形ABC。斜辺 $AB = c$、底辺 $AC = b$、高さ $BC = a$。$\angle\text{A} = \theta$ と表されている。]

また、三角形の内角の和は $180^\circ$ より

$$\angle \text{B} = 180^\circ - \angle \text{A} - \angle \text{C} = 180^\circ - \theta - 90^\circ = 90^\circ - \theta$$

よって

$$\sin(90^\circ - \theta) = \frac{b}{c}, \quad \cos(90^\circ - \theta) = \frac{a}{c}, \quad \tan(90^\circ - \theta) = \frac{b}{a}$$

以上より、次の関係が成り立つ。

---

### $90^\circ - \theta$ の三角比

$$\sin(90^\circ - \theta) = \cos\theta \quad\quad \cos(90^\circ - \theta) = \sin\theta \quad\quad \tan(90^\circ - \theta) = \frac{1}{\tan\theta}$$

---

ある鋭角が $45^\circ$ より大きいとき、その角度を $90^\circ - \bullet$ の形で表すと、$\bullet$ は $45^\circ$ より小さい角度となる。よって、上の関係を用いると、$45^\circ$ より大きい鋭角の三角比を、$45^\circ$ より小さい角の三角比で表すことができる。
