## 要点① $30^\circ, 45^\circ, 60^\circ$ の三角比

$\angle A = 30^\circ, \angle C = 90^\circ$ の直角三角形 ABC において，

$$BC : AB : AC = [ \quad ] : [ \quad ] : [ \quad ]$$

である。

[図の説明: $\angle C = 90^\circ, \angle A = 30^\circ$ の直角三角形ABC。]

ここで，$BC = 1, AB = 2, AC = \sqrt{3}$ とすると

$$\sin 30^\circ = [ \quad ], \quad \cos 30^\circ = [ \quad ], \quad \tan 30^\circ = [ \quad ]$$

である。

三角比の値は直角三角形の大きさによらないので，$\sin 30^\circ, \cos 30^\circ, \tan 30^\circ$ の値は常にこれらの値となる。

$\angle A = 60^\circ, \angle C = 90^\circ$ の直角三角形 ABC において，

$AC = 1, AB = 2, BC = \sqrt{3}$ とすると

[図の説明: $\angle C = 90^\circ, \angle A = 60^\circ$ の直角三角形ABC。]

$$\sin 60^\circ = [ \quad ], \quad \cos 60^\circ = [ \quad ], \quad \tan 60^\circ = [ \quad ]$$

であり，$\sin 60^\circ, \cos 60^\circ, \tan 60^\circ$ の値は常にこれらの値になる。

$\angle A = 45^\circ, \angle C = 90^\circ$ の直角三角形 ABC において，

$AC = 1, BC = 1, AB = \sqrt{2}$ とすると

[図の説明: $\angle C = 90^\circ, \angle A = 45^\circ$ の直角二等辺三角形ABC。]

$$\sin 45^\circ = [ \quad ], \quad \cos 45^\circ = [ \quad ], \quad \tan 45^\circ = [ \quad ]$$

であり，$\sin 45^\circ, \cos 45^\circ, \tan 45^\circ$ の値は常にこれらの値になる。

## 要点② 三角比の表

$30^\circ, 45^\circ, 60^\circ$ 以外の角についても，三角比の値は存在する。以下はその三角比の値を表す表の一部であり，それぞれの値は，小数第5位を四捨五入して小数第4位まで示した値である。

| $\theta$ | $\sin \theta$ | $\cos \theta$ | $\tan \theta$ |
| :---: | :---: | :---: | :---: |
| $\vdots$ | $\vdots$ | $\vdots$ | $\vdots$ |
| $29^\circ$ | $0.4848$ | $0.8746$ | $0.5543$ |
| $30^\circ$ | $0.5000$ | $0.8660$ | $0.5774$ |
| $31^\circ$ | $0.5150$ | $0.8572$ | $0.6009$ |
| $32^\circ$ | $0.5299$ | $0.8480$ | $0.6249$ |
| $33^\circ$ | $0.5446$ | $0.8387$ | $0.6494$ |
| $34^\circ$ | $0.5592$ | $0.8290$ | $0.6745$ |
| $35^\circ$ | $0.5736$ | $0.8192$ | $0.7002$ |
| $\vdots$ | $\vdots$ | $\vdots$ | $\vdots$ |

**【例】** 上の表より

$$\sin 32^\circ = [ \quad ], \quad \cos 32^\circ = [ \quad ], \quad \tan 32^\circ = [ \quad ]$$

上のような三角比の表を用いて，三角比の値から，角のおよその大きさを求めることができる。

**【例】** 右の図は，ある学校の階段の一部である。

[図の説明: 傾斜角 $\theta$、斜辺 $26\text{cm}$、高さ $18\text{cm}$ の直角三角形で表された階段の模式図。]

この階段の傾斜の角の大きさを $\theta$ とすると

$$\sin \theta = \frac{18}{26} = 0.69230\dots$$

上の表より，$\sin \theta$ の値が $0.6923$ に最も近い $\theta$ を求めて $\theta \fallingdotseq [ \quad ]^\circ$

※記号「 $\fallingdotseq$ 」は「ほぼ等しい」ことを表す。

### Point Pickup

**$30^\circ, 45^\circ, 60^\circ$ の三角比**

- $30^\circ$ の三角比 $\implies 30^\circ, 60^\circ, 90^\circ$ の直角三角形
- $45^\circ$ の三角比 $\implies 45^\circ, 45^\circ, 90^\circ$ の直角三角形
- $60^\circ$ の三角比 $\implies 60^\circ, 30^\circ, 90^\circ$ の直角三角形

をかき，3つの辺の比を実際の辺の長さとすることで，三角比の値を求めることができる。

# 解答 PART2 有名角の三角比，三角比の表

## 2 解答

**(1)**
- (i) $\sin 30^\circ = \dfrac{1}{2}, \quad \cos 30^\circ = \dfrac{\sqrt{3}}{2}, \quad \tan 30^\circ = \dfrac{1}{\sqrt{3}}$
- (ii) $\sin 45^\circ = \dfrac{1}{\sqrt{2}}, \quad \cos 45^\circ = \dfrac{1}{\sqrt{2}}, \quad \tan 45^\circ = 1$
- (iii) $\sin 60^\circ = \dfrac{\sqrt{3}}{2}, \quad \cos 60^\circ = \dfrac{1}{2}, \quad \tan 60^\circ = \sqrt{3}$

（参考図）
- (i) [図の説明: $\angle A=30^\circ, \angle C=90^\circ$ で、辺の長さが $AB=2, BC=1, AC=\sqrt{3}$ の直角三角形。]
- (ii) [図の説明: $\angle A=45^\circ, \angle C=90^\circ$ で、辺の長さが $AB=\sqrt{2}, BC=1, AC=1$ の直角二等辺三角形。]
- (iii) [図の説明: $\angle A=60^\circ, \angle C=90^\circ$ で、辺の長さが $AB=2, BC=\sqrt{3}, AC=1$ の直角三角形。]

**(2)**
このエスカレーターの傾斜の角の大きさを $\theta$ とすると

$$\sin \theta = \frac{42}{96} = 0.4375$$

三角比の表より，$\sin \theta$ の値が $0.4375$ に最も近い $\theta$ を求めて $\theta \fallingdotseq 26^\circ$

よって，傾斜の角の大きさは $26^\circ$
