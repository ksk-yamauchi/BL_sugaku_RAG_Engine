# 第 1 講 式の計算と展開

## PART1 単項式と多項式

---

### 要点① 単項式

「単項式」… $2$, $x$, $4ab^2$ のように，数，文字，および数や文字を掛け合わせて作られる式

「係数」… 単項式の [ 数の ] の部分  
**例** $3x^4$ の係数は [ $3$ ]

「次数」… 単項式の中で，掛け合わせた文字の [ 個数 ]  
**例** $-4x^2y^3 = -4 \times x \times x \times y \times y \times y$ より，$-4x^2y^3$ の次数は [ $5$ ]

$2$ など，数だけの単項式の次数は $0$ である。  
ただし，数 $0$ の次数は考えない（$0$ だけの項は，通常は書かないため）。

---

### 要点② ある文字に着目する

ある単項式が $2$ 種類以上の文字を含むとき，特定の文字に [ 着目 ] して係数や次数を考えることがある。特定の文字に着目した場合，他の文字は **（定数）** として扱う。

**例** $-ax^2y$ の係数は [ $-ay$ ]，次数は [ $2$ ]  
$a$ に着目すると [ $-x^2y \times a$ ] より，係数は [ $-x^2y$ ]，次数は [ $1$ ]  
$x$ と $y$ に着目すると [ $-a \times x^2y$ ] より，係数は [ $-a$ ]，次数は [ $3$ ]

---

### 要点③ 多項式

「多項式」… いくつかの単項式の [ 和 ] で表される式  
その $1$ つ $1$ つの単項式を「 [ 項 ] 」といい，数字だけの項を「 [ 定数項 ] 」という。

**例** $2x^2 - 3x + 4 = 2x^2 + (-3x) + 4$ より  
この式の項は [ $2x^2, -3x, 4$ ]，定数項は [ $4$ ]

---

多項式の各項の中で，次数が最も高い項の次数を，その多項式の次数といい，次数が $n$ である多項式を「 [ $n$ 次式 ] 」という。  
**例** $-3x^2 + 4x - 5$ は [ $2$ ] 次式である。

単項式と多項式を合わせて「 [ 整式 ] 」という。  
また，単項式を「項が $1$ つの多項式」と考えると，多項式は整式と同じ，と考えられる。

---

### 問題

**1**
(1) 次の単項式で，$[ \quad ]$ 内の文字に着目したときの，係数と次数をいえ。
$$-3ax^2y^3 \quad [a], [x]$$

(2) 次の多項式で，$[ \quad ]$ 内の文字に着目したとき，何次式であるかをいえ。また，それぞれの文字に着目したときの定数項をいえ。
$$3x^2 + x - 2y^3 + 4 \quad [x], [y]$$

---

### Point Pickup

#### **単項式の係数と次数**
ある文字に着目するときは，他の文字は「 **数（定数）** 」として扱う

#### **多項式の次数と定数項**
多項式の次数は，各項の中で，次数が最も高い項の次数である。  
また，多項式の定数項は，「（着目した）文字を含まない項」である。

# 第 1 講 PART1 確認問題

**1** 単項式 $-4x^3y^2$ について，$x$ に着目したとき，この単項式の係数は [ ア ] で，次数は [ イ ] である。

[ ア ] は，次の①～④のうちから選べ。  
① $-4$  
② $-4x^3$  
③ $4y^2$  
④ $-4y^2$  

**2** 単項式 $-4x^3y^2$ について，$y$ に着目したとき，この単項式の係数は [ ウ ] で，次数は [ エ ] である。

[ ウ ] は，次の①～④のうちから選べ。  
① $-4$  
② $4x^3$  
③ $-4x^3$  
④ $-4y^3$  

**3** 多項式 $4x^2 + x - 5y^3 - 2$ について，$x$ に着目したとき，この多項式は [ オ ] 次式であり，定数項は [ カ ] である。

[ カ ] は，次の①～④のうちから選べ。  
① $-2$  
② $x$  
③ $-5y^3$  
④ $-5y^3 - 2$  

**4** 多項式 $4x^2 + x - 5y^3 - 2$ について，$y$ に着目したとき，この多項式は [ キ ] 次式であり，定数項は [ ク ] である。

[ ク ] は，次の①～④のうちから選べ。  
① $-2$  
② $x - 2$  
③ $4x^2 + x - 2$  
④ $-5y^3 - 2$  

---

# 解答・解説

## **1** 解答

(1)
* $a$ に着目すると $-3x^2y^3 \times a$  
  よって，係数は $-3x^2y^3$，次数は $1$
* $x$ に着目すると $-3ay^3 \times x^2$  
  よって，係数は $-3ay^3$，次数は $2$

(2)
* $x$ に着目すると $3x^2 + x + (-2y^3 + 4)$  
  よって，$2$ 次式　　定数項は $-2y^3 + 4$
* $y$ に着目すると $-2y^3 + (3x^2 + x + 4)$  
  よって，$3$ 次式　　定数項は $3x^2 + x + 4$

---

## 確認問題 解答

**1** ［正解］ア：④，イ：3  
［解説］  
「$x$ に着目する」と指示があるので，$y$ は数と同様に扱う。
$$-4x^3y^2 = -4y^2 \times x^3$$
係数… $-4y^2$，次数… $3$

**2** ［正解］ウ：③，エ：2  
［解説］  
「$y$ に着目する」と指示があるので，$x$ は数と同様に扱う。
$$-4x^3y^2 = -4x^3 \times y^2$$
係数… $-4x^3$，次数… $2$

**3** ［正解］オ：2，カ：④  
［解説］  
「$x$ に着目する」と指示があるので，$y$ は数と同様に扱う。
$$4x^2 + x - 5y^3 - 2$$
$x$ に着目すると，$2$ 次式。  
定数項は，$-5y^3 - 2$

**4** ［正解］キ：3，ク：③  
［解説］  
「$y$ に着目する」と指示があるので，$x$ は数と同様に扱う。
$$4x^2 + x - 5y^3 - 2 = -5y^3 + 4x^2 + x - 2$$
$y$ に着目すると，$3$ 次式。  
定数項は，$4x^2 + x - 2$
