# PART3 2次関数の決定

### 要点① 頂点や軸に関する条件から2次関数の決定

頂点の座標や軸の方程式が条件として与えられたときは，求める2次関数の式を標準形
$$y = a(x - p)^2 + q$$
で表し，与えられた条件を用いて式を立てることができる。

#### 例
頂点が点 $(1, 2)$ であり，点 $(3, 10)$ を通る放物線をグラフにもつ2次関数を求める。  
頂点が点 $(1, 2)$ であることより，求める2次関数は
$$y = a(x - 1)^2 + 2$$
と表すことができる。  
グラフが点 $(3, 10)$ を通るから
$$10 = a(3 - 1)^2 + 2 \implies 4a = 8 \implies a = 2$$
よって，求める2次関数は $y = 2(x - 1)^2 + 2$

#### 例
軸が直線 $x = -2$ で，2点 $(1, -6)$，$(-4, -1)$ を通る放物線をグラフにもつ2次関数を求める。  
軸が直線 $x = -2$ であることより，求める2次関数は
$$y = a(x + 2)^2 + q$$
と表すことができる。  
グラフが点 $(1, -6)$，$(-4, -1)$ を通るから
$$
\begin{cases}
-6 = 9a + q \quad \dots \text{①} \\
-1 = 4a + q \quad \dots \text{②}
\end{cases}
$$
① - ②より $-5 = 5a \implies a = -1$  
②に代入して $-1 = -4 + q \implies q = 3$  
よって，求める2次関数は $y = -(x + 2)^2 + 3$

### 要点② グラフが通る 3 点から 2 次関数の決定

グラフが通る 3 点の座標が条件として与えられたときは，求める 2 次関数の式を一般形
$$y = ax^2 + bx + c$$
で表し，与えられた点の座標を用いて式を立てることができる。

#### 例
3 点 $(1, 4)$，$(-1, -4)$，$(2, 2)$ を通る放物線をグラフにもつ 2 次関数を求める。  
求める 2 次関数を
$$y = ax^2 + bx + c$$
とおく。この関数のグラフが 3 点 $(1, 4)$，$(-1, -4)$，$(2, 2)$ を通るから
$$
\begin{cases}
4 = a + b + c \quad \dots \text{①} \\
-4 = a - b + c \quad \dots \text{②} \\
2 = 4a + 2b + c \quad \dots \text{③}
\end{cases}
$$
① - ②より $2b = 8 \implies b = 4 \quad \dots \text{④}$  
④を①に代入して整理すると $a + c = 0 \quad \dots \text{⑤}$  
④を③に代入して整理すると $4a + c = -6 \quad \dots \text{⑥}$  
⑤，⑥より $a = -2, c = 2$  
よって，求める 2 次関数は $y = -2x^2 + 4x + 2$

上記の①，②，③のような，3 つの文字を含む 1 次方程式を連立した方程式を，**連立 3 元 1 次方程式**という。連立 3 元 1 次方程式を解くには，1 文字を消去し，残りの 2 文字についての連立方程式を解く，が基本である。

$$
\begin{cases}
4 = a + b + c \quad \dots \text{①} \\
-4 = a - b + c \quad \dots \text{②} \\
2 = 4a + 2b + c \quad \dots \text{③}
\end{cases}
$$
③ - ①より $3a + b = -2 \quad \dots \text{⑦}$  
③ - ②より $3a + 3b = 6 \implies a + b = 2 \quad \dots \text{⑧}$  
⑦，⑧より $a = -2, b = 4$  
これらを①に代入して $-2 + 4 + c = 4 \implies c = 2$

### Point Pickup

#### 2 次関数の決定（頂点や軸から）
頂点が点 $(\bullet, \blacksquare)$，軸の方程式が $x = \bullet$ である放物線をグラフにもつ 2 次関数は
$$y = a(x - \bullet)^2 + \blacksquare$$
と表される。

#### 2 次関数の決定（通る 3 点から）
求める 2 次関数の式を $y = ax^2 + bx + c$ とおき，グラフが通る 3 点の座標を用いて 3 つの 1 次方程式をつくり，それらを連立方程式として解く。  
3 つの式から 1 文字を消去し，残りの 2 文字についての連立方程式として解く，が基本方針となる。

次の条件を満たす放物線をグラフにもつ 2 次関数を求めよ。

(1) 頂点が点 $(2, 5)$ で，点 $(1, 6)$ を通る。  
(2) 軸の方程式が $x = -1$ で，2 点 $(1, -9)$，$(0, -3)$ を通る。  
(3) 3 点 $(1, 6)$，$(-1, 2)$，$(-2, 9)$ を通る。

#### ［解答］
**(1)**  
頂点が点 $(2, 5)$ であることより，求める 2 次関数は
$$y = a(x - 2)^2 + 5$$
と表すことができる。  
グラフが点 $(1, 6)$ を通るから
$$6 = a(1 - 2)^2 + 5 \implies a = 1$$
よって，求める 2 次関数は $y = (x - 2)^2 + 5$

**(2)**  
軸が直線 $x = -1$ であることより，求める 2 次関数は
$$y = a(x + 1)^2 + q$$
と表すことができる。  
グラフが 2 点 $(1, -9)$，$(0, -3)$ を通るから
$$
\begin{cases}
-9 = 4a + q \\
-3 = a + q
\end{cases}
$$
これを解いて，$a = -2, q = -1$  
よって，求める 2 次関数は $y = -2(x + 1)^2 - 1$

**(3)**  
求める 2 次関数を
$$y = ax^2 + bx + c$$
とおく。この関数のグラフが 3 点 $(1, 6)$，$(-1, 2)$，$(-2, 9)$ を通るから
$$
\begin{cases}
6 = a + b + c \quad \dots \text{①} \\
2 = a - b + c \quad \dots \text{②} \\
9 = 4a - 2b + c \quad \dots \text{③}
\end{cases}
$$
