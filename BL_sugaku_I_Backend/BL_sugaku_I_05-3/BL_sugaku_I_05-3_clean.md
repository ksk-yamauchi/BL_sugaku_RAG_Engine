# PART3 命題と条件

## 要点① 命題

「 [  ] 」… 正しいか正しくないかが明確に決まる文や式。

**例**
- 「$-1$ は自然数である」は 命題 [  ]
- 「10000 は大きい数である」は 命題 [  ]

命題が正しいとき，その命題は「 [  ] 」
命題が正しくないとき，その命題は「 [  ] 」
であるという。

**例**
- 「2 は 6 の約数である」は [  ] の命題である。
- 「$\sqrt{(-2)^2} = -2$」は [  ] の命題である。

---

## 要点② 命題と条件

「 [  ] 」… 文字を含む文や式のうち，文字のとる値を変えると真偽が変わるもの。

**例**
「$x > 2$」… $x=3$ のとき [  ] ，$x=2$ のとき [  ]

$x$ に関する 2 つの条件を
$$p : x > 3, \quad q : x \geqq 0$$
とする。命題「$x > 3$ ならば $x \geqq 0$」は，$p$，$q$ を用いると
「$p$ ならば $q$」
と表される。この命題を，記号「 [  ] 」を用いて
「$p \Rightarrow q$」
と表すことができる。

「$p \Rightarrow q$」という形の命題において
$p$ をこの命題の「 [  ] 」，$q$ をこの命題の「 [  ] 」
という。命題「$x > 3 \Rightarrow x \geqq 0$」においては
条件 [  ] が仮定，条件 [  ] が結論
である。

---

## 要点③ 命題の真偽と集合

命題「$x > 3$ ならば $x \geqq 0$」は真である。これを，集合を用いて考える。

- 条件 $x > 3$ を満たす実数 $x$ 全体の集合を $P$
- 条件 $x \geqq 0$ を満たす実数 $x$ 全体の集合を $Q$

とすると，$P \subset Q$ である。これを，数直線で表すと右図のようになる。

[図の説明: 数直線上に 0 と 3 が示されている。0 以上の範囲（0 の黒丸から右側全体）が集合 Q とされ斜線が引かれている。3 以上の範囲（3 の白丸から右側全体）が集合 P と示されており、集合 P は集合 Q に完全に含まれている（P ⊂ Q）。]

命題「$p \Rightarrow q$」の条件 $p$，$q$ について，全体集合 $U$ の要素の中で

- 条件 $p$ を満たすもの全体の集合を $P$
- 条件 $q$ を満たすもの全体の集合を $Q$

とすると，命題「$p \Rightarrow q$」が真であることは，$p$ を満たすものはすべて $q$ を満たす，すなわち $P \subset Q$ が成り立つことと同じである。

[図の説明: 全体集合 U を表す枠の中に集合 Q の円があり、その集合 Q の円の中に集合 P の円が完全に含まれている（P ⊂ Q）ベン図。集合 P の部分に斜線が引かれている。]

命題「$p \Rightarrow q$」が偽であるのは，仮定 $p$ を満たすが，結論 $q$ を満たさないものが存在するということである。それは，$P$ に属しているが $Q$ に属さない要素，すなわち [  ] に属する要素が存在する，ということである。
この要素を，この命題の「 [  ] 」という。

[図の説明: 全体集合 U の中で、集合 P の円と集合 Q の円が一部重なっているベン図。集合 P の円のうち、集合 Q と重なっていない部分（P ∩ Q̄）に斜線が引かれている。]

一般的に，命題が偽であることを示すには，反例を 1 つあげればよい。

**例** 命題「$x^2 = 4$ ならば $x = 2$」について
$x^2 = 4$ より $x = 2, -2$
よって，反例 $x = [  ]$ が存在するので，この命題は [  ] である。

## 演習問題 3

(1) 次の命題の真偽を調べよ。ただし，$x$，$y$ は実数とする。
- (i) $x=0$ ならば $xy=0$
- (ii) $x^2 = y^2$ ならば $x=y$
- (iii) $n$ は 18 の正の約数 $\Rightarrow n$ は 12 の正の約数

(2) 次の命題の真偽を調べよ。ただし，$x$ は実数とする。
- (i) $x < 2 \Rightarrow x < 5$
- (ii) $2 < x < 5 \Rightarrow 3 < x < 7$

---

## Point Pickup

### 命題の真偽
命題「$p \Rightarrow q$」について，条件 $p$ を満たすものが
- 条件 $q$ をすべて満たす …… 命題は真
- 条件 $q$ を満たさないもの（反例）がある …… 命題は偽

まずは，反例がないかを調べる。

### 集合を用いた命題の真偽
命題「$p \Rightarrow q$」について，条件 $p$，$q$ を満たすもの全体の集合をそれぞれ $P$，$Q$ とすると
- $P \subset Q$ …… 命題は真
- $P \cap \bar{Q}$ の要素が存在する …… 命題は偽

[図の説明: 左図は P ⊂ Q を表すベン図で「p ⇒ q は真」と記載。右図は P の円の一部が Q の外にはみ出しており P ∩ Q̄ に要素が存在することを表すベン図で「p ⇒ q は偽」と記載。]

実数の範囲を考えるときは，数直線を活用するとよい。

## 第 5 講 PART3 確認問題 解答

### 1
**［正解］** ア：①

**［解説］**
$x = -3$ のとき，$x^2 = (-3)^2 = 9$
よって，
「$x = -3$ ならば $x^2 = 9$」は真

［A］ 命題が常に成り立つときは真である。

---

### 2
**［正解］** イ：②

**［解説］**
$x^2 = 2x$ のとき
$$x^2 - 2x = 0$$
$$x(x - 2) = 0$$
$$x = 0, 2$$
よって，
「$x^2 = 2x$ ならば $x = 2$」は偽
反例：$x = 0$

［B］ 1つでも成り立たないものがあるときは，偽となる。

---

### 3
**［正解］** ウ：②

**［解説］**
$p$：「$n$ は 10 の正の約数」，$q$：「$n$ は 5 の正の約数」とする。
$p$ を満たす要素全体の集合を $P$
$q$ を満たす要素全体の集合を $Q$ とすると，
$$P = \{1, 2, 5, 10\}$$
$$Q = \{1, 5\}$$
$n = 2$ のとき，$n$ は 10 の約数であるが，5 の約数ではない。
よって，
「$n$ は 10 の正の約数ならば，$n$ は 5 の正の約数」は偽

反例：$n = 2$

［C］ 1つでも成り立たないものがあるときは，偽となる。

---

### 4
**［正解］** エ：①

**［解説］**
$p$：「$x > 1$」，$q$：「$x > 0$」とし，
$p$ を満たす要素全体の集合を $P$
$q$ を満たす要素全体の集合を $Q$ とすると，
$$P \subset Q$$

[図の説明: 数直線上で、x > 1 の範囲（集合 P）が x > 0 の範囲（集合 Q）に含まれていることを示す図。]

よって，
$p \Rightarrow q$ は真である。

［D］ $p \Rightarrow q$ が真であることは，$P \subset Q$ が成り立つことと同じである。

---

### 5
**［正解］** オ：②

**［解説］**
$p$：「$-2 < x < 2$」，$q$：「$0 < x < 1$」とする。
$p$ を満たす要素全体の集合を $P$
$q$ を満たす要素全体の集合を $Q$ とすると，
$P \subset Q$ でない。

[図の説明: 数直線上で、-2 < x < 2 の範囲（集合 P）の中に 0 < x < 1 の範囲（集合 Q）が含まれている（すなわち Q ⊂ P であり、P ⊂ Q は成り立たない）ことを示す図。]

よって，
$p \Rightarrow q$ は偽である。

［E］ $P \subset Q$ が成り立たないとき，$p \Rightarrow q$ は偽である。
