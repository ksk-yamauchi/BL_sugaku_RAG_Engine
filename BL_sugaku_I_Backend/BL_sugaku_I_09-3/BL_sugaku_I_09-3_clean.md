# PART3 ２次関数のグラフと $x$ 軸の共一点の座標

---

### **要点 ①** 関数のグラフと $x$ 軸の共一点の座標

$x$ 軸上の点は，その $y$ 座標が **$0$** である。よって，関数 $y = f(x)$ のグラフが $x$ 軸と共一点をもつとき，その共一点の $x$ 座標は，$y = f(x)$ で $y = 0$ となる $x$ の値，つまり方程式
$$f(x) = 0$$
の解である。

[図の説明: 座標平面上に曲線 $y=f(x)$ と直線 $y=0$ ($x$軸) が交わっている図。交点の $x$ 座標が $f(x)=0$ の解であることを示している。]

#### **例**
$y = -\dfrac{1}{2}x + 1$ のグラフと $x$ 軸との共一点の座標を求める。

方程式 $-\dfrac{1}{2}x + 1 = 0$ を解くと $x = 2$

よって，共一点の座標は $(2, 0)$

[図の説明: 座標平面上に右下がりの直線 $y=-\dfrac{1}{2}x+1$ が描かれている。$y$ 切片が $1$、$x$ 切片が $2$ であり、$x$ 軸との交点 $(2, 0)$ が $-\dfrac{1}{2}x+1=0$ の解であることを示している。]

---

### **要点 ②** ２次関数のグラフと $x$ 軸の共一点の座標

２次関数 $y = ax^2 + bx + c$ のグラフが $x$ 軸と共一点をもつとき，その共一点の $x$ 座標は，２次方程式 $ax^2 + bx + c = 0$ の **実数解** である。

#### **例**
$y = x^2 - 2x - 3$ のグラフと $x$ 軸の共一点の座標を求める。

２次方程式 $x^2 - 2x - 3 = 0$ を解くと
$$(x + 1)(x - 3) = 0 \text{ より } x = -1, 3$$

よって，共一点の座標は $(-1, 0), (3, 0)$

[図の説明: 下に凸の放物線 $y=x^2-2x-3$ のグラフ。$x$ 軸との交点が $(-1, 0)$ と $(3, 0)$、$y$ 軸との交点が $(0, -3)$ で描かれている。]

#### **例**
$y = -4x^2 + 4x - 1$ のグラフと $x$ 軸の共一点の座標を求める。

２次方程式 $-4x^2 + 4x - 1 = 0$ を解くと
$$4x^2 - 4x + 1 = 0 \text{ より } (2x - 1)^2 = 0 \quad x = \dfrac{1}{2}$$

よって，共一点の座標は $\left(\dfrac{1}{2}, 0\right)$

[図の説明: 上に凸の放物線 $y=-4x^2+4x-1$ のグラフ。頂点が $\left(\dfrac{1}{2}, 0\right)$ で $x$ 軸に接しており、$y$ 切片が $-1$ である。]

### **3**
次の 2 次関数のグラフと $x$ 軸の共一点の座標を求めよ。

(1) $y = x^2 + 2x - 8$
(2) $y = -x^2 + 6x + 4$
(3) $y = 2x^2 + 4x + 2$

#### **［解答］**

(1) 2 次方程式 $x^2 + 2x - 8 = 0$ を解くと
$$(x + 4)(x - 2) = 0 \text{ より } x = -4, 2$$
よって，共一点の座標は $(-4, 0), (2, 0)$

(2) 2 次方程式 $-x^2 + 6x + 4 = 0$ を解くと
$$x^2 - 6x - 4 = 0 \text{ より } x = \dfrac{-(-3) \pm \sqrt{(-3)^2 - 1 \cdot (-4)}}{1} = 3 \pm \sqrt{13}$$
よって，共一点の座標は $(3 - \sqrt{13}, 0), (3 + \sqrt{13}, 0)$

(3) 2 次方程式 $2x^2 + 4x + 2 = 0$ を解くと
$$x^2 + 2x + 1 = 0 \text{ より } (x + 1)^2 = 0 \quad x = -1$$
よって，共一点の座標は $(-1, 0)$

**(1)**
[図の説明: 下に凸の放物線 $y=x^2+2x-8$。$x$ 軸との交点が $(-4, 0)$ と $(2, 0)$、$y$ 軸との交点が $(0, -8)$ である。]

**(2)**
[図の説明: 上に凸の放物線 $y=-x^2+6x+4$。$x$ 軸との交点が $(3-\sqrt{13}, 0)$ と $(3+\sqrt{13}, 0)$、$y$ 軸との交点が $(0, 4)$ である。]

$y = -x^2 + 4x - 1$ のグラフと $x$ 軸の共一点の $x$ 座標は，
$$-x^2 + 4x - 1 = 0 \quad \text{［Ｂ］}$$
