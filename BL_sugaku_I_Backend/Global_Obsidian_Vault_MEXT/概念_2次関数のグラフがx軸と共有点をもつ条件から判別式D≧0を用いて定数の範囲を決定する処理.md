> **【💡 解説要約】**
> x軸との共有点のx座標が対応する二次方程式の実数解であることを理解し、グラフの位置関係を用いて二次不等式の解を求める解法を定着させる。

## 📌 スタサプ独自概要
2次関数 y = ax^2 + bx + c のグラフがx軸と共有点をもつ（異なる2点で交わる、または1点で接する）条件を、対応する2次方程式の判別式 D = b^2 - 4ac ≧ 0 と同値変形し、未定係数に関する不等式を立てて解を求める計算手順。

## ➡️ 前提知識 (重み付きネットワーク)
- `2次方程式の実数解の個数`
- `2次不等式の解法`

要点① 2次関数のグラフと $x$ 軸が共有点をもつ条件
2次関数 $y = ax^2 + bx + c$ のグラフと $x$ 軸が共有点をもつのは、2次方程式 $ax^2 + bx + c = 0$ の判別式を $D$ とすると
・$x$ 軸と異なる 2 点で交わる $\Longleftrightarrow D$
・$x$ 軸と 1 点で接する $\Longleftrightarrow D$
の 2 つの場合である。よって、次のことが成り立つ。
2次関数 $y = ax^2 + bx + c$ のグラフと $x$ 軸が共有点をもつ条件
2次方程式 $ax^2 + bx + c = 0$ の判別式を $D$ とすると
$x$ 軸と共有点をもつ $\Longleftrightarrow D \geqq 0$
  - 💡 理由: 2次関数のグラフがx軸と共有点をもつ条件について、判別式D ≧ 0 を用いて定数の範囲を決定する基本原理と計算手順を直接解説しているセグメントであるため。
