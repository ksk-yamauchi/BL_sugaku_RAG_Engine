# 概念(アクション): 最大の辺の対角が最大の角である性質を用いた角の吟味

> **【公式テキスト】**
> (ｳ) 正弦定理や余弦定理について三角形の決定条件や三平方の定理と関連付けて理解し，三角形の辺の長さや角の大きさなどを求めること。

> **【💡 解説要約】**
> 正弦定理・余弦定理の成り立ちを三角形の決定条件や三平方の定理と紐付けて理解し、未知の辺長や角の大きさを計算する技能を身に付けさせる。

## 📌 スタサプ独自概要
正弦定理等で求められた複数の角の可能性（例: $A=45^\circ, 135^\circ$）に対し、「三角形において最大の辺の対角が最大の角になる」という辺と角の大小関係（$c < b < a \implies C < B < A$）を用いて適する角を特定・排除する処理。
