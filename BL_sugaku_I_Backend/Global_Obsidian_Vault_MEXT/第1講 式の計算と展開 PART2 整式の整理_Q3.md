# 第1講 式の計算と展開 PART2 整式の整理 Q3

> **問題概要:** 整式 $x^3 + 3xy + 4y^2 - 2x + 7y - 8$ を $y$ について降べきの順に整理した式は [ オ ] である。

[ オ の選択肢 ]
① $x^3 + 4y^2 + 3xy - 2x + 7y - 8$
② $4y^2 + 7y + x^3 + (3y - 2)x - 8$
③ $4y^2 + (3x + 7)y + x^3 - 2x - 8$
④ $(x^3 - 2x - 8) + (3x + 7)y + 4y^2$

$2x^2+4xy-5x+3y+7$
$=4xy+3y+2x^2-5x+7$
