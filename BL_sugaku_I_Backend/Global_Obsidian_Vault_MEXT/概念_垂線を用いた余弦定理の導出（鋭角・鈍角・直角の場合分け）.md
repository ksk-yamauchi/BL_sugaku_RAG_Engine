# 概念(アクション): 垂線を用いた余弦定理の導出（鋭角・鈍角・直角の場合分け）

> **【公式テキスト】**
> (ｱ) 図形の構成要素間の関係を三角比を用いて表現するとともに，定理や公式として導くこと。

> **【💡 解説要約】**
> 三角形の辺と角の関係に着目して正弦定理や余弦定理などを論理的に導き出し、数式で鮮明に表現する力を養う。

## 📌 スタサプ独自概要
三角形の頂点から対辺（またはその延長）に垂線を下ろし、直角三角形における三平方の定理と三角比 $b \sin A$ や $b \cos A$ を利用して、$a^2 = b^2 + c^2 - 2bc \cos A$ を導出する処理。

## 🎬 📘 概念理解インプット講義動画
- **動画**: [[BL_sugaku_I_13-2-1.mp4]] (`02:03`〜`08:08`)
  - 📝 板書OCR: [1] $A, B$ がともに鋭角のとき 頂点 $\mathrm{C}$ から辺 $\mathrm{AB}$ に垂線 $\mathrm{CH}$ を下ろす。 直角三角形 $\mathrm{BCH}$ で、三平方の定理より $\mathrm{BC}^2 = \mathrm{CH}^2 + \mathrm{BH}^2$ すなわち $a^2 = \mathrm{CH}^2 + \mathrm{BH}^2 \quad \dots\dots \text{①}$ また、直角三角形 $\mathrm{ACH}$ において $\mathrm{CH} = b \sin A \quad \dots\dots \text{②}$ $\mathrm{AH} = b \cos A$ よって $\mathrm{BH} = \mathrm{AB} - \mathrm{AH} = c - b \cos A \quad \dots\dots \text{③}$ ①, ②, ③より $a^2 = (b \sin A)^2 + (c - b \cos A)^2 = b^2 \sin^2 A + c^2 - 2bc \cos A + b^2 \cos^2 A = b^2(\sin^2 A + \cos^2 A) + c^2 - 2bc \cos A = b^2 + c^2 - 2bc \cos A$ よって、$a^2 = b^2 + c^2 - 2bc \cos A$ が成り立つ。
  - 💡 理由: 頂点 $\mathrm{C}$ から対辺またはその延長線上に垂線 $\mathrm{CH}$ を下ろし、三平方の定理と三角比の定義を用いて鋭角・鈍角・直角の場合分けを行い、余弦定理 $a^2 = b^2 + c^2 - 2bc \cos A$ を証明・導出しているため。
