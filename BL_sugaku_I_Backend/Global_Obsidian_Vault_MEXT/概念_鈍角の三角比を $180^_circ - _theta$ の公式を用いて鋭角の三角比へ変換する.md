# 概念(アクション): 鈍角の三角比を $180^\circ - \theta$ の公式を用いて鋭角の三角比へ変換する

- [[親概念_三角比の補角の公式]]

> **【公式テキスト】**
> (ｲ) 三角比を鈍角まで拡張する意義を理解し，鋭角の三角比の値を用いて鈍角の三角比の値を求める方法を理解すること。

> **【💡 解説要約】**
> 座標平面上の半円を用いて角度の範囲を180°まで広げる意義を理解し、補角の公式などを活用して鈍角の三角比の値を求める方法を修得させる。

## 📌 スタサプ独自概要
補角の公式 $\sin(180^\circ - \theta) = \sin\theta$, $\cos(180^\circ - \theta) = -\cos\theta$, $\tan(180^\circ - \theta) = -\tan\theta$ を適用し、鈍角（$90^\circ < \theta < 180^\circ$）の三角比を鋭角の三角比へ直して値を計算・比較する処理。
