## 📝 関連する演習問題
```text
[問題] 次の多項式で，$[ \quad ]$ 内の文字に着目したとき，何次式であるかをいえ。また，それぞれの文字に着目したときの定数項をいえ。
$$3x^2 + x - 2y^3 + 4 \quad [x], [y]$$
[解説] [正解]
$x$ に着目したとき：$2$ 次式，定数項は $-2y^3 + 4$
$y$ に着目したとき：$3$ 次式，定数項は $3x^2 + x + 4$

[解説]
* $x$ に着目すると $3x^2 + x + (-2y^3 + 4)$ より，$2$ 次式で定数項は $-2y^3 + 4$
* $y$ に着目すると $-2y^3 + (3x^2 + x + 4)$ より，$3$ 次式で定数項は $3x^2 + x + 4$
```
```text
[問題] 多項式 $4x^2 + x - 5y^3 - 2$ について，$x$ に着目したとき，この多項式は [オ] 次式であり，定数項は [カ] である。

[カ] は，次の①～④のうちから選べ。
① $-2$
② $x$
③ $-5y^3$
④ $-5y^3 - 2$
[解説] [正解] オ：2，カ：④

[解説]
「$x$ に着目する」と指示があるので，$y$ は数と同様に扱う。
$$4x^2 + x - 5y^3 - 2$$
$x$ に着目すると，$2$ 次式。
定数項は，$-5y^3 - 2$
```
```text
[問題] 多項式 $4x^2 + x - 5y^3 - 2$ について，$y$ に着目したとき，この多項式は [キ] 次式であり，定数項は [ク] である。

[ク] は，次の①～④のうちから選べ。
① $-2$
② $x - 2$
③ $4x^2 + x - 2$
④ $-5y^3 - 2$
[解説] [正解] キ：3，ク：③

[解説]
「$y$ に着目する」と指示があるので，$x$ は数と同様に扱う。
$$4x^2 + x - 5y^3 - 2 = -5y^3 + 4x^2 + x - 2$$
$y$ に着目すると，$3$ 次式。
定数項は，$4x^2 + x - 2$
```
