# [問題] 第1講 式の計算と展開 PART3 整式の加法と減法，乗法_確認問題 3

## 📝 問題文
$A = 3x^2 + 4x - 1,\ B = x^2 - 2x - 5$ のとき、$3A-2B = [カ]x^2 + [キク]x + [ケ]$

## 💡 解説・解答
[正解]
カ：7，キク：16，ケ：7

[解説]
$3A-2B = 3(3x^2+4x-1)-2(x^2-2x-5) = 9x^2+12x-3-2x^2+4x+10 = 7x^2+16x+7$
括弧をつけて、$A, B$ を代入し，括弧をはずし，同類項をまとめる。
