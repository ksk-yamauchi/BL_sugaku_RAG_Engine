## 📌 スタサプ独自概要
$x$ の係数が1でない1次式の積 $(ax+b)(cx+d) = acx^2 + (ad+bc)x + bd$ において、たすき掛け的な積の和を算出して $x$ の係数を処理する計算アクション。

## ➡️ 前提知識 (重み付きネットワーク)
- **🔵 必須**: [[親概念_展開の公式]]
  - 💡 理由: 基本的1次式の展開公式 $(x+a)(x+b)$ の拡張概念であるため。
- **🔵 必須**: `同類項の整理` (※外部概念)
  - 💡 理由: $ad x$ と $bc x$ を同類項としてまとめて $(ad+bc)x$ とする計算技能が必要なため。

## 🎬 📘 概念理解インプット講義動画
- **動画**: [[BL_sugaku_I_01-4-2.mp4]] (`04:25`〜`06:39`)
  - 📝 板書OCR: $(ax+b)(cx+d)$ を展開し、$x$ に着目して整理すると
$(ax+b)(cx+d) = acx^2 + adx + bcx + bd = acx^2 + (ad+bc)x + bd$
であることから、次の展開の公式が成り立つ。

展開の公式
5 $(ax+b)(cx+d) = acx^2 + (ad+bc)x + bd$
