## 📝 関連する演習問題
```text
[問題] 次の整式を整理せよ。
$$x^2 + 3 - x^3 + 5x - 3x^2 - 2x^3 + 2$$
[解説] [正解] $-3x^3 - 2x^2 + 5x + 5$
[解説]
$x^2 + 3 - x^3 + 5x - 3x^2 - 2x^3 + 2$
$= -x^3 - 2x^3 + x^2 - 3x^2 + 5x + 3 + 2$
$= (-1 - 2)x^3 + (1 - 3)x^2 + 5x + (3 + 2)$
$= -3x^3 - 2x^2 + 5x + 5$
```
```text
[問題] 次の整式を，[ ] 内の文字に着目して整理せよ。
$$2x^2 + 4xy - 5x + 3y + 7 \quad [x], [y]$$
[解説] [正解] 
$x$ に着目すると $2x^2 + (4y - 5)x + (3y + 7)$
$y$ に着目すると $(4x + 3)y + (2x^2 - 5x + 7)$

[解説]
$x$ に着目すると
$2x^2 + 4xy - 5x + 3y + 7$
$= 2x^2 + 4yx - 5x + 3y + 7$
$= 2x^2 + (4y - 5)x + (3y + 7)$

$y$ に着目すると
$2x^2 + 4xy - 5x + 3y + 7$
$= 4xy + 3y + 2x^2 - 5x + 7$
$= (4x + 3)y + (2x^2 - 5x + 7)$
```
```text
[問題] 次の整式を整理せよ。
$$5a^3 - 4 + a^2 - 7a^2 + 5a + 9$$
$$= [ア]a^3 - [イ]a^2 + 5a + [ウ]$$
[解説] [正解] ア：5，イ：6，ウ：5
[解説]
$$5a^3 - 4 + a^2 - 7a^2 + 5a + 9 = 5a^3 - 6a^2 + 5a + 5$$
文字の部分が同じ項（同類項）をまとめる。
```
```text
[問題] 整式 $x^3 + 3xy + 4y^2 - 2x + 7y - 8$ を $x$ について降べきの順に整理した式は [エ] である。

[ エ の選択肢 ]
① $x^3 + 4y^2 + 3xy - 2x + 7y - 8$
② $x^3 + (3y - 2)x + 4y^2 + 7y - 8$
③ $x^3 - 2x + 4y^2 + (3x + 7)y - 8$
④ $(4y^2 + 7y - 8) + (3y - 2)x + x^3$
[解説] [正解] エ：②
[解説]
$x^3 + 3xy + 4y^2 - 2x + 7y - 8$
$= x^3 + (3y - 2)x + 4y^2 + 7y - 8$
「$x$ について」と指示があるので，$y$ は定数とみなす。
```
```text
[問題] 整式 $x^3 + 3xy + 4y^2 - 2x + 7y - 8$ を $y$ について降べきの順に整理した式は [オ] である。

[ オ の選択肢 ]
① $x^3 + 4y^2 + 3xy - 2x + 7y - 8$
② $4y^2 + 7y + x^3 + (3y - 2)x - 8$
③ $4y^2 + (3x + 7)y + x^3 - 2x - 8$
④ $(x^3 - 2x - 8) + (3x + 7)y + 4y^2$
[解説] [正解] オ：③
[解説]
$x^3 + 3xy + 4y^2 - 2x + 7y - 8$
$= 4y^2 + (3x + 7)y + x^3 - 2x - 8$
「$y$ について」と指示があるので，$x$ は定数とみなす。
```
