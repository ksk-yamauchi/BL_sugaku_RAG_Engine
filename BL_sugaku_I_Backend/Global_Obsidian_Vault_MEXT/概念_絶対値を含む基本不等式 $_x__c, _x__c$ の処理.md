# 概念(アクション): 絶対値を含む基本不等式 $|x|<c, |x|>c$ の処理

## 🔼 親概念 (Level 3)
- [[親概念_絶対値を含む不等式]]

## 🏛️ 指導要領アライメント
- **観点分類**: `知識・技能`
- **階層**: 高等学校 > 数学 > 数学Ⅰ > 内容 > (1) 数と式 > ア > (ｴ)
- **指導要領コード**: `8451503114000000`

> **【公式テキスト】**
> (ｴ) 不等式の解の意味や不等式の性質について理解し，一次不等式の解を求めること。

> **【💡 解説要約】**
> 不等式の性質（負の数を掛けた際の不等号の反転等）と解の意味を理解し、一次不等式を確実に解く技能を養う。

## 📌 スタサプ独自概要
$c > 0$ のとき、距離に着目して $|x| < c \iff -c < x < c$ や $|x| > c \iff x < -c, c < x$ と解の範囲を立式・変換する処理。

## ➡️ 前提知識 (重み付きネットワーク)
- **🔵 必須**: `絶対値の定義` (※外部概念)
  - 💡 理由: 数直線上の原点からの距離と不等式が表す区間の関係を理解する必要があるため。
- **🔵 必須**: `一次不等式` (※外部概念)
  - 💡 理由: 不等号の向きや範囲の表現方法を理解している必要があるため。
