# 第8講 2次関数の最大・最小，2次関数の決定 PART3 2次関数の決定 Q3

> **問題概要:** 3 点 $(0, 3)$，$(1, 1)$，$(-1, 9)$ を通る。
$$y = [\text{キ}] x^2 - [\text{ク}] x + [\text{ケ}]$$

## 🔗 対象の数理概念（Level 4）
- [[概念_通る3点から一般形y=ax^2+bx+cを立てて決定する]]

## 🎬 紐付けられた解説セグメント
### 📘 概念理解（前提となる基礎・解説講義）
- **🔵 パターンB** [[BL_sugaku_I_08-3-2.mp4]] (`00:00`〜`00:53`)
  - 📝 板書OCR: 要点2 グラフが通る 3 点から 2 次関数の決定
グラフが通る 3 点の座標が条件として与えられたときは、求める 2 次関数の式を一般形
$y = ax^2 + bx + c$
で表し、与えられた点の座標を用いて式を立てることができる。
  - 💡 理由: 通る 3点から一般形 $y = ax^2 + bx + c$ を立式する前提概念を講義しているため。
- **🔵 パターンB** [[BL_sugaku_I_08-3-2.mp4]] (`04:26`〜`07:16`)
  - 📝 板書OCR: 上記の①、②、③のような、3つの文字を含む1次方程式を連立した方程式を、連立3元1次方程式という。連立3元1次方程式を解くには、1文字を消去し、残りの2文字についての連立方程式を解く、が基本である。
$$\begin{cases} 4 = a + b + c & \dots \text{①} \\ -4 = a - b + c & \dots \text{②} \\ 2 = 4a + 2b + c & \dots \text{③} \end{cases}$$
③ - ①より $3a + b = -2 \quad \dots \text{⑦}$
③ - ②より $3a + 3b = 6 \quad \text{よって} \quad a + b = 2 \quad \dots \text{⑧}$
⑦、⑧より $a = -2, b = 4$
これらを①に代入して $-2 + 4 + c = 4 \quad c = 2$
  - 💡 理由: 得られた 3元1次連立方程式から 1文字を消去して解く計算の前提手法を講義しているため。
