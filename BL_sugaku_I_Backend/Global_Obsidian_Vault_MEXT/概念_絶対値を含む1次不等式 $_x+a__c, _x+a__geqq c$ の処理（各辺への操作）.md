# 概念(アクション): 絶対値を含む1次不等式 $|x+a|<c, |x+a|\geqq c$ の処理（各辺への操作）

## 🔼 親概念 (Level 3)
- [[親概念_絶対値を含む不等式]]

## 🏛️ 指導要領アライメント
- **観点分類**: `思考力・判断力等`

> **【公式テキスト】**
> (ｳ) 不等式の性質を基に一次不等式を解く方法を考察すること。

> **【💡 解説要約】**
> 等式の性質との比較を通して不等式の性質を理解し、どのような手順で一次不等式を解くことができるか論理的に考察させる。

## 📌 スタサプ独自概要
$x+a$ をひとつのまとまりとして扱い、$-c < x+a < c$ や $x+a \leqq -c, c \leqq x+a$ から各辺に $-a$ を加えて $x$ の範囲を求める計算アクション。

## ➡️ 前提知識 (重み付きネットワーク)
- **🔵 必須**: [[親概念_絶対値を含む不等式]]
  - 💡 理由: 基本形 $|X| < c \iff -c < X < c$ 等の変換ルールを前提とするため。
- **🔵 必須**: `一次不等式の解法` (※外部概念)
  - 💡 理由: 連立不等式状の各辺に同じ数を加えたり引き算したりして $x$ の範囲に整理する技能が必要なため。
