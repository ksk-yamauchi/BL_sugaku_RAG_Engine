## 📝 関連する演習問題
```text
[問題] 次の整式を整理せよ。
$$x^2 + 3 - x^3 + 5x - 3x^2 - 2x^3 + 2$$
[解説] [正解] $-3x^3 - 2x^2 + 5x + 5$
[解説]
$x^2 + 3 - x^3 + 5x - 3x^2 - 2x^3 + 2$
$= -x^3 - 2x^3 + x^2 - 3x^2 + 5x + 3 + 2$
$= (-1 - 2)x^3 + (1 - 3)x^2 + 5x + (3 + 2)$
$= -3x^3 - 2x^2 + 5x + 5$
```
```text
[問題] 次の整式を，[ ] 内の文字に着目して整理せよ。
$$2x^2 + 4xy - 5x + 3y + 7 \quad [x], [y]$$
[解説] [正解]
$x$ に着目：$2x^2 + (4y - 5)x + (3y + 7)$
$y$ に着目：$(4x + 3)y + (2x^2 - 5x + 7)$
[解説]
$x$ に着目すると
$2x^2 + 4xy - 5x + 3y + 7$
$= 2x^2 + 4yx - 5x + 3y + 7$
$= 2x^2 + (4y - 5)x + (3y + 7)$

$y$ に着目すると
$2x^2 + 4xy - 5x + 3y + 7$
$= 4xy + 3y + 2x^2 - 5x + 7$
$= (4x + 3)y + (2x^2 - 5x + 7)$
```
```text
[問題] 次の整式を整理せよ。
$$5a^3 - 4 + a^2 - 7a^2 + 5a + 9$$
$$= [ア]a^3 - [イ]a^2 + 5a + [ウ]$$
[解説] [正解] ア：5，イ：6，ウ：5
[解説]
$$5a^3 - 4 + a^2 - 7a^2 + 5a + 9 = 5a^3 - 6a^2 + 5a + 5$$
［Ａ］ 文字の部分が同じ項（同類項）をまとめる。
```
