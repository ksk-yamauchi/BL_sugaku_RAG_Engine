# 第12講 三角比の拡張 PART2 単位円を用いた三角比の定義 Q1

> **問題概要:** 次の三角比の値を，単位円を用いて求めよ。
ただし， [ ア ] ～ [ シ ] は，下の①～⑥のうちから選べ。

[図の説明: 単位円上に角度30°の動径が描かれ、点Pからx軸、y軸に垂線が下ろされている。y軸上の値にイ、x軸上の値にアが割り振られている。]

$$\sin 30^\circ = \text{[ ウ ]} \quad, \quad \cos 30^\circ = \text{[ エ ]}$$

① $\frac{1}{2}$　② $\sqrt{3}$　③ $\frac{\sqrt{3}}{2}$
④ $-\frac{1}{2}$　⑤ $-\sqrt{3}$　⑥ $-\frac{\sqrt{3}}{2}$

## 🎬 紐付けられた解説セグメント
### 📘 概念理解（前提となる基礎・解説講義）
- **🔵 パターンB** [[BL_sugaku_I_12-2-1.mp4]] (`03:52`〜`05:16`)
  - 📝 板書OCR: $30^\circ$ の正弦および余弦の値を単位円で考える。
$\angle\text{A} = 30^\circ, \angle\text{C} = 90^\circ$ の直角三角形 $\text{ABC}$ において
$\text{AB} = 2$ のとき $\text{BC} = 1, \text{AC} = \sqrt{3}$
$\text{AB} = 1$ のとき $\text{BC} = \frac{1}{2}, \text{AC} = \frac{\sqrt{3}}{2}$
である。よって, 単位円を用いると
$\sin 30^\circ = \frac{1}{2} , \cos 30^\circ = \frac{\sqrt{3}}{2}$
である。
  - 💡 理由: 単位円上に斜辺 $1$ の $30^\circ$ の直角三角形をあてはめ、点 $\text{P}$ の座標および $\sin 30^\circ, \cos 30^\circ$ を求める基本的な手順を導出・解説しているため。
