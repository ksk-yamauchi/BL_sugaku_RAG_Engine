# [問題] 第1講 式の計算と展開 PART3 整式の加法と減法，乗法_確認問題 2

## 📝 問題文
$A = 3x^2 + 4x - 1,\ B = x^2 - 2x - 5$ のとき、
$$A-B = [ウ]x^2 + [エ]x + [オ]$$

## 💡 解説・解答
[正解] ウ：2，エ：6，オ：4
[解説]
$A-B = (3x^2+4x-1)-(x^2-2x-5) = 3x^2+4x-1-x^2+2x+5 = 2x^2+6x+4$
