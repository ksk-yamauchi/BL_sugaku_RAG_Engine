# 第6講 命題と論証 PART1 逆・裏・対偶 Q2

> **問題概要:** $x$ を実数として，次の命題を $P$ とする。  
「$x \neq 1$ ならば，$x^2 \neq x$ である」  
命題 $P$ の逆・裏・対偶をそれぞれ述べよ。また，命題 $P$ および逆・裏・対偶の真偽を調べよ。

| | | 真偽 |
|---|---|---|
| $P$ | $x \neq 1$ ならば，<br>$x^2 \neq x$ である | [ サ ] |
| $P$ の逆 | [ ク ] | [ シ ] |
| $P$ の裏 | [ ケ ] | [ ス ] |
| $P$ の対偶 | [ コ ] | [ セ ] |

**[ ク ～ コ の選択肢 ]**
- ① $x = 1$ ならば，$x^2 \neq x$ である
- ② $x = 1$ ならば，$x^2 = x$ である
- ③ $x^2 = x$ ならば，$x = 1$ である
- ④ $x^2 \neq x$ ならば，$x \neq 1$ である

**[ サ ～ セ の選択肢 ]**
- ① 真
- ② 偽

## 🔗 対象の数理概念（Level 4）
- [[概念_否定を含む命題を対偶命題に変換して同値な真偽判定を行う]]

## 🎬 紐付けられた解説セグメント
### 📘 概念理解（前提となる基礎・解説講義）
- **🔵 パターンB** [[BL_sugaku_I_06-1-2.mp4]] (`04:27`〜`07:07`)
  - 📝 板書OCR: 例 命題 『$x+y<0 \Rightarrow x<0 \text{ または } y<0$』 の真偽について
この命題の対偶は 『$x \geqq 0 \text{ かつ } y \geqq 0 \Rightarrow x+y \geqq 0$』
これは明らかに 真 である。よって、もとの命題も 真 である。
  - 💡 理由: 否定等を含む判定しにくい命題を対偶に変換して真偽判定を行う考え方を解説したインプット講義であるため。

### 📗 例題演習（本問題の解法直接解説）
- **🟢 パターンA** [[BL_sugaku_I_06-1-3.mp4]] (`06:42`〜`07:30`)
  - 📝 板書OCR: (2)\ x \neq 1 \text{ ならば } x^2 - 4x + 3 \neq 0 \text{ である。
  - 💡 理由: 問題2と同型である「$\neq$（否定）」を含む条件の命題に対して、対偶をつくって二次方程式の形に変換して真偽判定を行う手順を直接解説しているセグメントであるため。
