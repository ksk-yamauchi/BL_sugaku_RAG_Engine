# 概念(アクション): 1次の係数が偶数の場合に判別式D/4を用いてx軸との共有点の有無を判定する処理

> **【公式テキスト】**
> (ｳ) 二次方程式の解と二次関数のグラフとの関係について理解すること。また，二次不等式の解と二次関数のグラフとの関係について理解し，二次関数のグラフを用いて二次不等式の解を求めること。

> **【💡 解説要約】**
> x軸との共有点のx座標が対応する二次方程式の実数解であることを理解し、グラフの位置関係を用いて二次不等式の解を求める解法を定着させる。

## 📌 スタサプ独自概要
2次方程式 ax^2 + 2b'x + c = 0 において、1次の係数が偶数の際に D/4 = b'^2 - ac を用いて計算を簡略化し、D/4 < 0 からグラフがx軸と共有点をもたないことを迅速に確認する処理。
