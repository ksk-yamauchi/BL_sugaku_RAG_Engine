# 概念(アクション): 判別式D<0の場合における2次不等式の解の判定

## 🏛️ 指導要領アライメント
- **観点分類**: `知識・技能`
- **階層**: 高等学校 > 数学 > 数学Ⅰ > 内容 > (3) 二次関数 > ア > (ｳ)

> **【公式テキスト】**
> (ｳ) 二次方程式の解と二次関数のグラフとの関係について理解すること。また，二次不等式の解と二次関数のグラフとの関係について理解し，二次関数のグラフを用いて二次不等式の解を求めること。

> **【💡 解説要約】**
> x軸との共有点のx座標が対応する二次方程式の実数解であることを理解し、グラフの位置関係を用いて二次不等式の解を求める解法を定着させる。

## 📌 スタサプ独自概要
2次方程式の判別式がD<0のとき、2次関数のグラフがx軸と共有点をもたない（x軸の上に浮いている）ことを把握し、a>0において不等号の向き（>0, ≧0, <0, ≦0）に応じて解が「すべての実数」または「解はない」となることを判定・処理する計算アクション。

## 🎬 📘 概念理解インプット講義動画
- **動画**: [[BL_sugaku_I_10-3-1.mp4]] (`00:05`〜`02:09`)
  - 📝 板書OCR: $$\text{例 2次不等式 } x^2 - 3x + 5 > 0, x^2 - 3x + 5 \leqq 0 \text{ を解く。}$$ $$\text{方程式 } x^2 - 3x + 5 = 0 \dots\dots \text{①の解を求めるために、解の公式を用いると}$$ $$x = \frac{-(-3) \pm \sqrt{(-3)^2 - 4 \cdot 1 \cdot 5}}{2 \cdot 1} = \frac{3 \pm \sqrt{-11}}{2}$$ $$\text{判別式 } D = (-3)^2 - 4 \cdot 1 \cdot 5 = -11 < 0$$
  - 💡 理由: 2次方程式の判別式D<0を計算し、実数解をもたない（グラフがx軸と共地点をもたない）ことから不等式の解を判定する基本手順を解説しているため。
- **動画**: [[BL_sugaku_I_10-3-1.mp4]] (`07:45`〜`09:12`)
  - 📝 板書OCR: $$\text{2次関数 } y = ax^2 + bx + c \quad (a > 0) \text{ のグラフが } x \text{ 軸と共地点をもたないとき}$$ $$ax^2 + bx + c > 0 \text{ の解：すべての実数}$$ $$ax^2 + bx + c \geqq 0 \text{ の解：すべての実数}$$ $$ax^2 + bx + c < 0 \text{ の解：ない}$$ $$ax^2 + bx + c \leqq 0 \text{ の解：ない}$$
  - 💡 理由: a>0かつ判別式D<0の場合における2次不等式の解（すべての実数 / ない）のパターンを網羅的に整理・解説しているため。
