# 第12講 三角比の拡張 PART4 $180^\circ-\theta$ の三角比，単位円と三角比の相互関係 Q6

> **問題概要:** $0^\circ \leqq \theta \leqq 180^\circ$ とする。$\tan\theta = -\frac{4}{3}$ のとき，
$$\cos\theta = \text{[ ク ]}, \quad \sin\theta = \text{[ ケ ]}$$
である。

[ ク ] , [ ケ ] は次の①～⑥のうちから選べ。

① $\frac{3}{5}$
② $\frac{4}{5}$
③ $\frac{3}{4}$
④ $-\frac{3}{5}$
⑤ $-\frac{4}{5}$
⑥ $-\frac{3}{4}$

### 📗 例題演習（本問題の解法直接解説）
- **🟢 パターンA** [[BL_sugaku_I_12-4-3.mp4]] (`07:55`〜`08:38`)
  - 📝 板書OCR: (iii) $0^\circ \leqq \theta \leqq 180^\circ$ とする。$\tan\theta = -2$ のとき，$\cos\theta, \sin\theta$ の値を求めよ。
$1 + \tan^2\theta = \frac{1}{\cos^2\theta}$ より $\frac{1}{\cos^2\theta} = 1 + \tan^2\theta = 1 + (-2)^2 = 5$
$\cos^2\theta = \frac{1}{5}$
  - 💡 理由: 負の正接 $\tan\theta = -2$ から $1 + \tan^2\theta = \frac{1}{\cos^2\theta}$ を用い、$\theta$ が鈍角であることから $\cos\theta < 0$ を判定して $\cos\theta$ と $\sin\theta$ を求める解法を直接解説しているセグメントであるため。
