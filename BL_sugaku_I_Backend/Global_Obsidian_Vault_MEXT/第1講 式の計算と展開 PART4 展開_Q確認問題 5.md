# 第1講 式の計算と展開 PART4 展開 Q確認問題 5

> **問題概要:** $(2x-3)(x+4) = 2x^2 + \text{[ ケ ]}x - \text{[ コサ ]}$

## 🔗 対象の数理概念（Level 4）
- [[概念_一般の1次式の積の展開公式 $(ax+b)(cx+d)$ の適用]]

## 🎬 紐付けられた解説セグメント
### 📘 概念理解（前提となる基礎・解説講義）
- **🔵 パターンB** [[BL_sugaku_I_01-4-2.mp4]] (`04:25`〜`06:39`)
  - 📝 板書OCR: $(ax+b)(cx+d)$ を展開し、$x$ に着目して整理すると
$(ax+b)(cx+d) = acx^2 + adx + bcx + bd = acx^2 + (ad+bc)x + bd$
であることから、次の展開の公式が成り立つ。

展開の公式
5 $(ax+b)(cx+d) = acx^2 + (ad+bc)x + bd$
  - 💡 理由: 一般の1次式の積の展開公式 $(ax+b)(cx+d) = acx^2 + (ad+bc)x + bd$ の解説を行っているインプットセグメントであるため。
