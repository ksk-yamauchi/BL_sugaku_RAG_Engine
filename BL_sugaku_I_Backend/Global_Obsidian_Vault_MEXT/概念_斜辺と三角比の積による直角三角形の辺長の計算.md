要点① 三角比の利用
右の図の直角三角形において
$\sin \theta = \frac{a}{c}$, $\cos \theta = \frac{b}{c}$, $\tan \theta = \frac{a}{b}$
である。これらの式を変形すると、以下の等式が成り立つ。
$a = c \sin \theta$
$b = c \cos \theta$
$a = b \tan \theta$
  - 💡 理由: 直角三角形における三角比の定義から、斜辺 $c$ と $\sin \theta$, $\cos \theta$ を用いて高さ $a = c \sin \theta$ および底辺 $b = c \cos \theta$ を求める公式の導出と概念の直接解説を行っているため。
