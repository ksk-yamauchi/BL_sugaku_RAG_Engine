# 概念(アクション): 鈍角条件における $\sin\theta$ から相互関係式 $\sin^2\theta + \cos^2\theta = 1$ を用いて符号を判定し $\cos\theta, \tan\theta$ を求める

> **【公式テキスト】**
> (ｲ) 三角比を鈍角まで拡張する意義を理解し，鋭角の三角比の値を用いて鈍角の三角比の値を求める方法を理解すること。

> **【💡 解説要約】**
> 座標平面上の半円を用いて角度の範囲を180°まで広げる意義を理解し、補角の公式などを活用して鈍角の三角比の値を求める方法を修得させる。

## 📌 スタサプ独自概要
角の範囲が $90^\circ < \theta < 180^\circ$（鈍角）のとき、与えられた $\sin\theta$ の値から $\cos^2\theta = 1 - \sin^2\theta$ を計算し、$\cos\theta < 0$ に着目して負の平方根をとることで $\cos\theta$ を求め、さらに $\tan\theta = \frac{\sin\theta}{\cos\theta}$ を用いて $\tan\theta$ を算術的に導出する処理。

  - 📝 板書OCR: 例 $90^\circ < \theta < 180^\circ$ とする。$\sin\theta = \frac{3}{5}$ のとき、$\cos\theta$, $\tan\theta$ の値を求めよ。\n$\sin^2\theta + \cos^2\theta = 1$ より、$\cos^2\theta = 1 - \sin^2\theta = 1 - \left(\frac{3}{5}\right)^2 = 1 - \frac{9}{25} = \frac{16}{25}$\n$90^\circ < \theta < 180^\circ$ より、$\cos\theta < 0$ であるから $\cos\theta = -\frac{4}{5}$\nまた $\tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{3}{5} \div \left(-\frac{4}{5}\right) = \frac{3}{5} \times \left(-\frac{5}{4}\right) = -\frac{3}{4}$
