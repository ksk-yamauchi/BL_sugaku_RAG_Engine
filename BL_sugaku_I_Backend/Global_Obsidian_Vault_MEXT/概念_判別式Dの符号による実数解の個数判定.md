# 概念(アクション): 判別式Dの符号による実数解の個数判定

> **【公式テキスト】**
> (ｳ) 二次方程式の解と二次関数のグラフとの関係について理解すること。また，二次不等式の解と二次関数のグラフとの関係について理解し，二次関数のグラフを用いて二次不等式の解を求めること。

> **【💡 解説要約】**
> x軸との共有点のx座標が対応する二次方程式の実数解であることを理解し、グラフの位置関係を用いて二次不等式の解を求める解法を定着させる。

## 📌 スタサプ独自概要
2次方程式 $ax^2 + bx + c = 0$ において判別式 $D = b^2 - 4ac$ を計算し、$D > 0$（2個）、$D = 0$（1個・重解）、$D < 0$（0個）により実数解の個数を特定する処理手順。

## ➡️ 前提知識 (重み付きネットワーク)
- `2次方程式の解の公式`
- `実数の性質`

## 🎬 📘 概念理解インプット講義動画
- **動画**: [[BL_sugaku_I_09-2-1.mp4]] (`05:37`〜`06:47`)
  - 📝 板書OCR: 2次方程式の実数解の個数
2次方程式 $ax^2 + bx + c = 0$ の判別式 $D = b^2 - 4ac$ について
$D > 0 \iff$ 異なる2つの実数解をもつ
$D = 0 \iff$ ただ1つの実数解（重解）をもつ
$D < 0 \iff$ 実数解をもたない
  - 💡 理由: 判別式 $D = b^2 - 4ac$ の符号（$D > 0$, $D = 0$, $D < 0$）によって実数解の個数がそれぞれ2個、1個（重解）、0個となる基本的な関係性とルールが直接解説されているセグメントであるため。
