# 概念(アクション): 判別式の符号による2次関数のグラフとx軸の位置関係の判定

## 🏛️ 指導要領アライメント
- **観点分類**: `知識・技能`

> **【公式テキスト】**
> (ｳ) 二次方程式の解と二次関数のグラフとの関係について理解すること。また，二次不等式の解と二次関数のグラフとの関係について理解し，二次関数のグラフを用いて二次不等式の解を求めること。

> **【💡 解説要約】**
> x軸との共有点のx座標が対応する二次方程式の実数解であることを理解し、グラフの位置関係を用いて二次不等式の解を求める解法を定着させる。

## 📌 スタサプ独自概要
2次関数 $y = ax^2 + bx + c$ のグラフと $x$ 軸の位置関係を、対応する2次方程式 $ax^2 + bx + c = 0$ の判別式 $D = b^2 - 4ac$ の符号（$D > 0$：異なる2点で交わる、$D = 0$：接する、$D < 0$：共有点をもたない）を調べて判定する。
