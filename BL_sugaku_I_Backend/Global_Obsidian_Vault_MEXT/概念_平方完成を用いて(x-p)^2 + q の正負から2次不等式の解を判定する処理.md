# 概念(アクション): 平方完成を用いて(x-p)^2 + q の正負から2次不等式の解を判定する処理

## 🔼 親概念 (Level 3)

## 🏛️ 指導要領アライメント
- **観点分類**: `知識・技能`
- **階層**: 高等学校 > 数学 > 数学Ⅰ > 内容 > (3) 二次関数 > ア > (ｳ)
- **指導要領コード**: `8451503313000000`

> **【公式テキスト】**
> (ｳ) 二次方程式の解と二次関数のグラフとの関係について理解すること。また，二次不等式の解と二次関数のグラフとの関係について理解し，二次関数のグラフを用いて二次不等式の解を求めること。

> **【💡 解説要約】**
> x軸との共有点のx座標が対応する二次方程式の実数解であることを理解し、グラフの位置関係を用いて二次不等式の解を求める解法を定着させる。

## 📌 スタサプ独自概要
2次式を平方完成して (x-p)^2 + q の形に変形し、(x-p)^2 ≧ 0 であることから常に正（または負）の値をとることを示し、判別式を使わずに不等式の解（すべての実数 / 解はない）を論理的に導く別解処理。

  - 📝 板書OCR: $$y = x^2 - 3x + 5 = \left(x - \frac{3}{2}\right)^2 + \frac{11}{4}$$ $$\text{不等式 } x^2 - 3x + 5 > 0 \text{ の解：すべての実数}$$ $$\text{不等式 } x^2 - 3x + 5 \leqq 0 \text{ の解：解はない}$$
  - 💡 理由: 2次式を平方完成して(x-p)^2 + qの形に変形し、グラフがx軸の上に浮いている（常に正の値をとる）ことを論理的に示して解を決定する別解アプローチを解説しているため。
