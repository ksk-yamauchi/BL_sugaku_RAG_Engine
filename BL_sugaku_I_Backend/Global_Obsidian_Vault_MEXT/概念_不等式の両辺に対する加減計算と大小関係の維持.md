# 概念(アクション): 不等式の両辺に対する加減計算と大小関係の維持

> **【公式テキスト】**
> (ｴ) 不等式の解の意味や不等式の性質について理解し，一次不等式の解を求めること。

> **【💡 解説要約】**
> 不等式の性質（負の数を掛けた際の不等号の反転等）と解の意味を理解し、一次不等式を確実に解く技能を養う。

## 📌 スタサプ独自概要
不等号の両辺に同じ数を加えても（$A + C < B + C$）、同じ数を引いても（$A - C < B - C$）、数の大小関係（不等号の向き）が変わらないという性質を適用する。

## ➡️ 前提知識 (重み付きネットワーク)
- **🔵 必須**: [[親概念_不等式の性質]]
  - 💡 理由: 両辺に同じ数を足し引きしても不等号の向きが変わらない基本性質を理解している必要があるため。
- **🟡 補足**: `正の数・負の数` (※外部概念)
  - 💡 理由: 負の数を加減する際の符号処理を正しく行うため。

## 🎬 📘 概念理解インプット講義動画
- **動画**: [[BL_sugaku_I_04-1-2.mp4]] (`02:04`〜`03:27`)
  - 📝 板書OCR: $a < b$ のとき $a + 2 < b + 2, \quad a - 2 < b - 2$ に見られるように、両辺に同じ数を足しても、両辺から同じ数を引いても、大小関係は変わらない。
  - 💡 理由: 不等式の両辺に同じ数を加えたり引いたりしても、大小関係（不等号の向き）が変わらないという基本性質について数直線を用いて解説しているため。
