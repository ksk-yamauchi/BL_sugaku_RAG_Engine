## 📝 関連する演習問題
```text
[問題] 次の式を展開せよ。
$(x-4y)(x-6y)$
[解説] [正解] $x^2 - 10xy + 24y^2$
[解説]
$(x-4y)(x-6y) = x^2 + \{(-4y) + (-6y)\}x + (-4y) \cdot (-6y) = x^2 - 10xy + 24y^2$
```
```text
[問題] 次の式を展開せよ。
$(2x+3)(3x+4)$
[解説] [正解] $6x^2 + 17x + 12$
[解説]
$(2x+3)(3x+4) = 2 \cdot 3x^2 + (2 \cdot 4 + 3 \cdot 3)x + 3 \cdot 4 = 6x^2 + 17x + 12$
```
```text
[問題] 次の式を展開せよ。
$(x+5y)(3x-7y)$
[解説] [正解] $3x^2 + 8xy - 35y^2$
[解説]
$(x+5y)(3x-7y) = 3x^2 + (-7y + 15y)x + 5y \cdot (-7y) = 3x^2 + 8xy - 35y^2$
```
```text
[問題] 次の式を展開せよ。
$(x-y-8)(x-y+2)$
[解説] [正解] $x^2 - 2xy + y^2 - 6x + 6y - 16$
[解説]
$x-y = A$ とおくと
$(x-y-8)(x-y+2) = (A-8)(A+2) = A^2 - 6A - 16$
$= (x-y)^2 - 6(x-y) - 16$
$= x^2 - 2xy + y^2 - 6x + 6y - 16$
```
```text
[問題] 次の式を展開せよ。
$(x-2a)(x-3a) = x^2 - [キ]ax + [ク]a^2$
[解説] [正解] キ：5，ク：6
[解説]
$(x-2a)(x-3a) = x^2 + \{(-2a) + (-3a)\}x + (-2a) \cdot (-3a)$
$= x^2 - 5ax + 6a^2$
展開の公式 $(x+a)(x+b) = x^2 + (a+b)x + ab$ を利用する。
```
```text
[問題] 次の式を展開せよ。
$(2x-3)(x+4) = 2x^2 + [ケ]x - [コサ]$
[解説] [正解] ケ：5，コサ：12
[解説]
$(2x-3)(x+4) = 2 \cdot 1x^2 + \{2 \cdot 4 + (-3) \cdot 1\}x + (-3) \cdot 4$
$= 2x^2 + 5x - 12$
展開の公式 $(ax+b)(cx+d) = acx^2 + (ad+bc)x + bd$ を利用する。
```
```text
[問題] 次の式を展開せよ。
$(x+2y)(3x+4y) = [シ]x^2 + [スセ]xy + [ソ]y^2$
[解説] [正解] シ：3，スセ：10，ソ：8
[解説]
$(x+2y)(3x+4y) = 1 \cdot 3x^2 + (1 \cdot 4y + 2y \cdot 3)x + 2y \cdot 4y$
$= 3x^2 + 10xy + 8y^2$
展開の公式 $(ax+b)(cx+d) = acx^2 + (ad+bc)x + bd$ を利用する。
```
```text
[問題] 次の式を展開せよ。
$(x+y-2)(x+y+5) = x^2 + [タ]xy + y^2 + [チ]x + [ツ]y - [テト]$
[解説] [正解] タ：2，チ：3，ツ：3，テト：10
[解説]
$x+y = A$ とおくと
$(x+y-2)(x+y+5) = (A-2)(A+5)$
$= A^2 + 3A - 10$
$= (x+y)^2 + 3(x+y) - 10$
$= x^2 + 2xy + y^2 + 3x + 3y - 10$
括弧の中の共通な式を，別の文字でおき換えて展開する。
```
