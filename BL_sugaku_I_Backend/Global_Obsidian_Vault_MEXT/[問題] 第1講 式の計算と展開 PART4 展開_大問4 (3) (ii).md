# [問題] 第1講 式の計算と展開 PART4 展開_大問4 (3) (ii)

## 📝 問題文
次の式を展開せよ。
$(a+b+c)^2$

## 💡 解説・解答
[正解] $a^2 + b^2 + c^2 + 2ab + 2bc + 2ca$
[解説] $a+b = A$ とおくと
$(a+b+c)^2 = (A+c)^2 = A^2 + 2Ac + c^2$
$= (a+b)^2 + 2(a+b)c + c^2$
$= a^2 + 2ab + b^2 + 2ac + 2bc + c^2$
$= a^2 + b^2 + c^2 + 2ab + 2bc + 2ca$
