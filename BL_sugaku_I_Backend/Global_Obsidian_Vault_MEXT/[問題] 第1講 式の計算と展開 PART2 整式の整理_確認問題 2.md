# [問題] 第1講 式の計算と展開 PART2 整式の整理_確認問題 2

## 📝 問題文
整式 $x^3 + 3xy + 4y^2 - 2x + 7y - 8$ を $x$ について降べきの順に整理した式は [エ] である。

[ エ の選択肢 ]
① $x^3 + 4y^2 + 3xy - 2x + 7y - 8$
② $x^3 + (3y - 2)x + 4y^2 + 7y - 8$
③ $x^3 - 2x + 4y^2 + (3x + 7)y - 8$
④ $(4y^2 + 7y - 8) + (3y - 2)x + x^3$

## 💡 解説・解答
[正解] エ：②
[解説]
$$x^3 + 3xy + 4y^2 - 2x + 7y - 8$$
$$= x^3 + (3y - 2)x + 4y^2 + 7y - 8$$
［Ｂ］ 「$x$ について」と指示があるので，$y$ は定数とみなす。
