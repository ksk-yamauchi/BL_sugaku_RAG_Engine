# 第5講 集合，命題と条件 PART4 必要条件と十分条件，条件の否定 Q7

> **問題概要:** 「$x > 0 \text{ または } y \leqq 1$」
この条件の否定は [ キ ] である。

[ キ ] は次の①～③のうちから選べ。
① $x < 0 \text{ かつ } y > 1$
② $x \leqq 0 \text{ かつ } y > 1$
③ $x \leqq 0 \text{ または } y > 1$
