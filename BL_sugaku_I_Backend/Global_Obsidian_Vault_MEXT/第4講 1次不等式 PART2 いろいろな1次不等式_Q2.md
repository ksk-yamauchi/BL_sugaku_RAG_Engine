# 第4講 1次不等式 PART2 いろいろな1次不等式 Q2

> **問題概要:** 不等式 $-x+6 \leqq 3x-2 < 6x+1$ の解は， [ イ ] である。

[ イ ] は，次の①～④のうちから選べ。
① $x < -1$
② $x \leqq 2$
③ $x \geqq 2$
④ $-1 < x \leqq 2$

## 🔗 対象の数理概念（Level 4）
- [[概念_A _ B _ C 型の不等式を連立1次不等式に変形して解く]]

## 🎬 紐付けられた解説セグメント
### 📘 概念理解（前提となる基礎・解説講義）
- **🔵 パターンB** [[BL_sugaku_I_04-2-1.mp4]] (`07:33`〜`09:51`)
  - 📝 板書OCR: 不等式 $A < B < C$ は、2つの不等式 $A < B$, $B < C$ が同時に成り立つことを表した式である。\nよって、不等式 $A < B < C$ は、連立不等式 $\begin{cases} A < B \\ B < C \end{cases}$ と同じである。
  - 💡 理由: $A < B < C$ 型の不等式を同値な連立不等式に変形する理論と解法のインプットが確認できるため。

### 📗 例題演習（本問題の解法直接解説）
- **🟢 パターンA** [[BL_sugaku_I_04-2-3.mp4]] (`03:04`〜`04:14`)
  - 📝 板書OCR: (2) \text{ 不等式 } -3x-2 \leqq 2x+1 < 5x-11 \text{ を解け。}\\ \begin{cases} -3x-2 \leqq 2x+1 & \cdots\cdots \text{①} \\ 2x+1 < 5x-11 & \cdots\cdots \text{②} \end{cases}
  - 💡 理由: $A \leqq B < C$ 型の不等式を連立不等式に分解してそれぞれの共通範囲を求める同形式の演習問題の解説が行われているため。
