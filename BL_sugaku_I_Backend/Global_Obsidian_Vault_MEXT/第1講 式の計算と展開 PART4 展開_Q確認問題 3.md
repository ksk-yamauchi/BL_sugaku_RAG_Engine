# 第1講 式の計算と展開 PART4 展開 Q確認問題 3

### 📘 概念理解（前提となる基礎・解説講義）
- **🔵 パターンB** [[BL_sugaku_I_01-4-2.mp4]] (`00:05`〜`02:44`)
  - 📝 板書OCR: 要点 2 展開の公式
展開する式がある特別な形をしているとき、以下の「展開の公式」により、その展開の途中計算を省略することができる。

展開の公式
1 $(a+b)^2 = a^2 + 2ab + b^2$
2 $(a-b)^2 = a^2 - 2ab + b^2$
3 $(a+b)(a-b) = a^2 - b^2$
4 $(x+a)(x+b) = x^2 + (a+b)x + ab$
  - 💡 理由: 和と差の積の展開公式 $(a+b)(a-b) = a^2 - b^2$ の基本的な解説を行っているインプットセグメントであるため。
