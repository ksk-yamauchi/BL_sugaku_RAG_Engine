# [タスク] 置き換えを利用して多項式を展開する

## 📝 関連する演習問題
```text
[問題] 次の式を展開せよ。
$(x-y-8)(x-y+2)$
[解説] [正解] $x^2 - 2xy + y^2 - 6x + 6y - 16$
[解説]
$x-y = A$ とおくと
$(x-y-8)(x-y+2) = (A-8)(A+2) = A^2 - 6A - 16$
$= (x-y)^2 - 6(x-y) - 16$
$= x^2 - 2xy + y^2 - 6x + 6y - 16$
```
```text
[問題] 次の式を展開せよ。
$(a+b+c)^2$
[解説] [正解] $a^2 + b^2 + c^2 + 2ab + 2bc + 2ca$
[解説]
$a+b = A$ とおくと
$(a+b+c)^2 = (A+c)^2 = A^2 + 2Ac + c^2$
$= (a+b)^2 + 2(a+b)c + c^2$
$= a^2 + 2ab + b^2 + 2ac + 2bc + c^2$
$= a^2 + b^2 + c^2 + 2ab + 2bc + 2ca$
```
```text
[問題] 次の式を展開せよ。
$(x+y-2)(x+y+5) = x^2 + [タ]xy + y^2 + [チ]x + [ツ]y - [テト]$
[解説] [正解] タ：2，チ：3，ツ：3，テト：10
[解説]
$x+y = A$ とおくと
$(x+y-2)(x+y+5) = (A-2)(A+5)$
$= A^2 + 3A - 10$
$= (x+y)^2 + 3(x+y) - 10$
$= x^2 + 2xy + y^2 + 3x + 3y - 10$
括弧の中の共通な式を，別の文字でおき換えて展開する。
```
```text
[問題] 次の式を展開せよ。
$(a+2b-3)^2 = a^2 + [ナ]ab + [ニ]b^2 - [ヌ]a - [ネノ]b + [ハ]$
[解説] [正解] ナ：4，ニ：4，ヌ：6，ネノ：12，ハ：9
[解説]
$a+2b = A$ とおくと
$(a+2b-3)^2 = (A-3)^2$
$= A^2 - 6A + 9$
$= (a+2b)^2 - 6(a+2b) + 9$
$= a^2 + 4ab + 4b^2 - 6a - 12b + 9$
括弧の中の一部の式を，別の文字でおき換えて展開する。
```
