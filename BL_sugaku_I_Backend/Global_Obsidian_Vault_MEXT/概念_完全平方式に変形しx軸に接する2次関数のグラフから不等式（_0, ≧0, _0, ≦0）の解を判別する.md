# 概念(アクション): 完全平方式に変形しx軸に接する2次関数のグラフから不等式（>0, ≧0, <0, ≦0）の解を判別する

- [[親概念_2次不等式]]

## 🏛️ 指導要領アライメント
- **観点分類**: `知識・技能`
- **階層**: 高等学校 > 数学 > 数学Ⅰ > 内容 > (3) 二次関数 > ア > (ｳ)

> **【公式テキスト】**
> (ｳ) 二次方程式の解と二次関数のグラフとの関係について理解すること。また，二次不等式の解と二次関数のグラフとの関係について理解し，二次関数のグラフを用いて二次不等式の解を求めること。

> **【💡 解説要約】**
> x軸との共有点のx座標が対応する二次方程式の実数解であることを理解し、グラフの位置関係を用いて二次不等式の解を求める解法を定着させる。

## 📌 スタサプ独自概要
2次式を $(x-\alpha)^2$ や $(ax+b)^2$ の形に因数分解して $x$ 軸との接点 $(\alpha, 0)$ を特定し、不等号の種類（ $>0$, $\geqq 0$, $<0$, $\leqq 0$ ）に応じて「$\alpha$ 以外のすべての実数」「すべての実数」「解はない」「$x=\alpha$」という4つの解のパターンを正しく分類・処理する。
