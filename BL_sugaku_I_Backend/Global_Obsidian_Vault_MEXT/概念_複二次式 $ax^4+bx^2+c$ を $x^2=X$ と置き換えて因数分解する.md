## 📌 スタサプ独自概要
$x^4 = (x^2)^2$ であることを利用し、$x^2=X$ と置き換えることで $X$ の $2$ 次式に変換し、因数分解を行ったあとに元の $x^2$ に戻し、可能ならさらに因数分解を進める計算アクション。

## ➡️ 前提知識 (重み付きネットワーク)
- **🔵 必須**: [[親概念_因数分解]]
  - 💡 理由: 置き換え後の $X$ の $2$ 次式を因数分解し、さらに $x^2$ に戻した後の $x^2-a^2 = (x+a)(x-a)$ などの公式適用に必須であるため。
- **🟡 補足**: [[親概念_指数法則]]
  - 💡 理由: $x^4 = (x^2)^2$ という構造変形を理解するために有用であるため。

## 🎬 📘 概念理解インプット講義動画
- **動画**: [[BL_sugaku_I_02-4-1.mp4]] (`04:28`〜`05:31`)
  - 📝 板書OCR: $x^4+2x^2-3$ の因数分解 $x^4+2x^2-3 = (x^2)^2+2x^2-3$ より、$x^2=X$ とおくと $x^4+2x^2-3 = X^2+2X-3$
  - 💡 理由: $x^4=(x^2)^2$ であることに着目し、$x^2=X$ と置くことで $X$ の $2$ 次式に変換できる理由を直接解説しているため。
- **動画**: [[BL_sugaku_I_02-4-1.mp4]] (`05:31`〜`07:08`)
  - 📝 板書OCR: $x^4+2x^2-3$ の因数分解 $x^4+2x^2-3 = (x^2)^2+2x^2-3$ より、$x^2=X$ とおくと $x^4+2x^2-3 = X^2+2X-3 = (X-1)(X+3) = (x^2-1)(x^2+3) = (x+1)(x-1)(x^2+3)$
  - 💡 理由: $x^2=X$ と置いた因数分解の実行から、元の $x^2$ に戻した後にさらに因数分解する手順までを直接解説しているため。
