## 📝 関連する演習問題
```text
[問題] 次の式を展開せよ。
$(2x+1)^2$
[解説] [正解] $4x^2 + 4x + 1$
[解説]
$(2x+1)^2 = (2x)^2 + 2 \cdot 2x \cdot 1 + 1^2 = 4x^2 + 4x + 1$
```
```text
[問題] 次の式を展開せよ。
$(3x-2y)^2$
[解説] [正解] $9x^2 - 12xy + 4y^2$
[解説]
$(3x-2y)^2 = (3x)^2 - 2 \cdot 3x \cdot 2y + (2y)^2 = 9x^2 - 12xy + 4y^2$
```
```text
[問題] 次の式を展開せよ。
$(a+b+c)^2$
[解説] [正解] $a^2 + b^2 + c^2 + 2ab + 2bc + 2ca$
[解説]
$a+b = A$ とおくと
$(a+b+c)^2 = (A+c)^2 = A^2 + 2Ac + c^2$
$= (a+b)^2 + 2(a+b)c + c^2$
$= a^2 + 2ab + b^2 + 2ac + 2bc + c^2$
$= a^2 + b^2 + c^2 + 2ab + 2bc + 2ca$
```
```text
[問題] 次の式を展開せよ。
$(x+3)^2 = x^2 + [ア]x + [イ]$
[解説] [正解] ア：6，イ：9
[解説]
$(x+3)^2 = x^2 + 2 \cdot x \cdot 3 + 3^2$
$= x^2 + 6x + 9$
展開の公式 $(a+b)^2 = a^2 + 2ab + b^2$ を利用する。
```
```text
[問題] 次の式を展開せよ。
$(2x-1)^2 = [ウ]x^2 - [エ]x + 1$
[解説] [正解] ウ：4，エ：4
[解説]
$(2x-1)^2 = (2x)^2 - 2 \cdot 2x \cdot 1 + 1^2$
$= 4x^2 - 4x + 1$
展開の公式 $(a-b)^2 = a^2 - 2ab + b^2$ を利用する。
```
```text
[問題] 次の式を展開せよ。
$(a+2b-3)^2 = a^2 + [ナ]ab + [ニ]b^2 - [ヌ]a - [ネノ]b + [ハ]$
[解説] [正解] ナ：4，ニ：4，ヌ：6，ネノ：12，ハ：9
[解説]
$a+2b = A$ とおくと
$(a+2b-3)^2 = (A-3)^2$
$= A^2 - 6A + 9$
$= (a+2b)^2 - 6(a+2b) + 9$
$= a^2 + 4ab + 4b^2 - 6a - 12b + 9$
括弧の中の一部の式を，別の文字でおき換えて展開する。
```
