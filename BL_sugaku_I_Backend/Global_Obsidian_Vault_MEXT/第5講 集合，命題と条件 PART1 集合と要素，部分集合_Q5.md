# 第5講 集合，命題と条件 PART1 集合と要素，部分集合 Q5

> **問題概要:** $A = \{2, 4, 6, 8, 10\}$，$B = \{2n \mid n = 1, 2, 3, 4, 5\}$ のとき，[ ソ ] である。

[ ソ ] は，最も適当なものを，次の①～③のうちから選べ。
① $A \subset B$
② $A \supset B$
③ $A = B$
