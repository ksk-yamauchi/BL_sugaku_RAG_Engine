# 第13講 正弦定理・余弦定理 PART4 三角形の決定 Q1

> **問題概要:** $\triangle ABC$ において，$a=4, b=3, c=2$ のとき，$A$ は [ ア ] である。

[ ア ] は，次の①～③のうちから選べ。
① 鋭角　　② 直角　　③ 鈍角

### 📗 例題演習（本問題の解法直接解説）
- **🟢 パターンA** [[BL_sugaku_I_13-4-1.mp4]] (`06:16`〜`08:53`)
  - 📝 板書OCR: \text{例 } \triangle ABC \text{ において，} a=7, b=4, c=5 \text{ のとき，} A \text{ は鋭角，直角，鈍角のいずれであるか求める。}
4^2+5^2 = 41, 7^2 = 49 \text{ より } 4^2+5^2 < 7^2 \quad \text{つまり } b^2+c^2 < a^2
\text{よって，} A \text{ は鈍角である。}
  - 💡 理由: 3辺の長さから $b^2+c^2$ と $a^2$ を計算・比較し、$b^2+c^2 < a^2$ より角 $A$ が鈍角であると判定する同構造の例題を直接解説しているため。
- **🟢 パターンA** [[BL_sugaku_I_13-4-3.mp4]] (`01:49`〜`03:37`)
  - 📝 板書OCR: 4 (1) $\triangle ABC$ において、$a=7, b=6, c=5$ のとき、$A$ は鋭角、直角、鈍角のいずれであるか。
$$6^2+5^2=61, 7^2=49 \text{ より } 6^2+5^2>7^2$$
$$\text{つまり } b^2+c^2>a^2$$
$$\text{よって、余弦定理より、} A \text{ は鋭角である。}$$
  - 💡 理由: 演習問題として3辺の長さが与えられたときの2乗比較と角の判定手順を詳しく解説しているため。
