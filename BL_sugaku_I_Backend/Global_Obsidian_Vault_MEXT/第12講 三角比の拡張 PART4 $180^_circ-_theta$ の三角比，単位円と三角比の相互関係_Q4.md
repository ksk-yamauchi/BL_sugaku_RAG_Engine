# 第12講 三角比の拡張 PART4 $180^\circ-\theta$ の三角比，単位円と三角比の相互関係 Q4

> **問題概要:** $90^\circ < \theta < 180^\circ$ とする。$\sin\theta = \frac{\sqrt{7}}{4}$ のとき，
$$\cos\theta = \text{[ エ ]}, \quad \tan\theta = \text{[ オ ]}$$
である。

[ エ ] , [ オ ] は次の①～⑥のうちから選べ。

① $-\frac{\sqrt{7}}{4}$
② $\frac{3}{4}$
③ $-\frac{3}{4}$
④ $\frac{\sqrt{7}}{3}$
⑤ $-\frac{\sqrt{7}}{3}$
⑥ $\frac{1}{4}$

### 📗 例題演習（本問題の解法直接解説）
- **🟢 パターンA** [[BL_sugaku_I_12-4-3.mp4]] (`04:34`〜`05:25`)
  - 📝 板書OCR: $\sin^2\theta + \cos^2\theta = 1$ より $\cos^2\theta = 1 - \sin^2\theta$
$= 1 - \left(\frac{4}{5}\right)^2 = 1 - \frac{16}{25} = \frac{9}{25}$
$90^\circ < \theta < 180^\circ$ より，$\cos\theta < 0$ であるから $\cos\theta = -\frac{3}{5}$
  - 💡 理由: 鈍角条件（$90^\circ < \theta < 180^\circ$）で $\sin\theta$ から $\sin^2\theta + \cos^2\theta = 1$ を用いて $\cos\theta < 0$ を求め、さらに $\tan\theta = \frac{\sin\theta}{\cos\theta}$ を計算する解法を直接説明しているセグメントであるため。
