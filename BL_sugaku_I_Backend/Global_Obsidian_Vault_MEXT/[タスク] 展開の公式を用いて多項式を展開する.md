## 📝 関連する演習問題
```text
[問題] 次の式を展開せよ。
$(2x+1)^2$
[解説] [正解] $4x^2 + 4x + 1$
[解説] $(2x+1)^2 = (2x)^2 + 2 \cdot 2x \cdot 1 + 1^2 = 4x^2 + 4x + 1$
```
```text
[問題] 次の式を展開せよ。
$(3x-2y)^2$
[解説] [正解] $9x^2 - 12xy + 4y^2$
[解説] $(3x-2y)^2 = (3x)^2 - 2 \cdot 3x \cdot 2y + (2y)^2 = 9x^2 - 12xy + 4y^2$
```
```text
[問題] 次の式を展開せよ。
$(3x+5y)(3x-5y)$
[解説] [正解] $9x^2 - 25y^2$
[解説] $(3x+5y)(3x-5y) = (3x)^2 - (5y)^2 = 9x^2 - 25y^2$
```
```text
[問題] 次の式を展開せよ。
$(x-4y)(x-6y)$
[解説] [正解] $x^2 - 10xy + 24y^2$
[解説] $(x-4y)(x-6y) = x^2 + \{(-4y) + (-6y)\}x + (-4y) \cdot (-6y) = x^2 - 10xy + 24y^2$
（別解） $(x-4y)(x-6y) = x^2 + (-4-6)xy + (-4) \cdot (-6)y^2 = x^2 - 10xy + 24y^2$
```
```text
[問題] 次の式を展開せよ。
$(2x+3)(3x+4)$
[解説] [正解] $6x^2 + 17x + 12$
[解説] $(2x+3)(3x+4) = 2 \cdot 3x^2 + (2 \cdot 4 + 3 \cdot 3)x + 3 \cdot 4 = 6x^2 + 17x + 12$
```
```text
[問題] 次の式を展開せよ。
$(x+5y)(3x-7y)$
[解説] [正解] $3x^2 + 8xy - 35y^2$
[解説] $(x+5y)(3x-7y) = 3x^2 + (-7y + 15y)x + 5y \cdot (-7y) = 3x^2 + 8xy - 35y^2$
（別解） $(x+5y)(3x-7y) = 3x^2 + (-7 + 15)xy - 35y^2 = 3x^2 + 8xy - 35y^2$
```
```text
[問題] 次の式を展開せよ。
$(x+3)^2 = x^2 + [ア]x + [イ]$
[解説] [正解] ア：6，イ：9
[解説] $(x+3)^2 = x^2 + 2 \cdot x \cdot 3 + 3^2 = x^2 + 6x + 9$
［Ａ］展開の公式： $(a+b)^2 = a^2 + 2ab + b^2$
```
```text
[問題] 次の式を展開せよ。
$(2x-1)^2 = [ウ]x^2 - [エ]x + 1$
[解説] [正解] ウ：4，エ：4
[解説] $(2x-1)^2 = (2x)^2 - 2 \cdot 2x \cdot 1 + 1^2 = 4x^2 - 4x + 1$
［Ｂ］展開の公式： $(a-b)^2 = a^2 - 2ab + b^2$
```
```text
[問題] 次の式を展開せよ。
$(x+4y)(x-4y) = x^2 - [オカ]y^2$
[解説] [正解] オカ：16
[解説] $(x+4y)(x-4y) = x^2 - (4y)^2 = x^2 - 16y^2$
［Ｃ］展開の公式： $(a+b)(a-b) = a^2 - b^2$
```
```text
[問題] 次の式を展開せよ。
$(x-2a)(x-3a) = x^2 - [キ]ax + [ク]a^2$
[解説] [正解] キ：5，ク：6
[解説] $(x-2a)(x-3a) = x^2 + \{(-2a) + (-3a)\}x + (-2a) \cdot (-3a) = x^2 - 5ax + 6a^2$
［Ｄ］展開の公式： $(x+a)(x+b) = x^2 + (a+b)x + ab$
```
```text
[問題] 次の式を展開せよ。
$(2x-3)(x+4) = 2x^2 + [ケ]x - [コサ]$
[解説] [正解] ケ：5，コサ：12
[解説] $(2x-3)(x+4) = 2 \cdot 1x^2 + \{2 \cdot 4 + (-3) \cdot 1\}x + (-3) \cdot 4 = 2x^2 + 5x - 12$
［Ｅ］展開の公式： $(ax+b)(cx+d) = acx^2 + (ad+bc)x + bd$
```
```text
[問題] 次の式を展開せよ。
$(x+2y)(3x+4y) = [シ]x^2 + [スセ]xy + [ソ]y^2$
[解説] [正解] シ：3，スセ：10，ソ：8
[解説] $(x+2y)(3x+4y) = 1 \cdot 3x^2 + (1 \cdot 4y + 2y \cdot 3)x + 2y \cdot 4y = 3x^2 + 10xy + 8y^2$
［Ｆ］展開の公式： $(ax+b)(cx+d) = acx^2 + (ad+bc)x + bd$
```
