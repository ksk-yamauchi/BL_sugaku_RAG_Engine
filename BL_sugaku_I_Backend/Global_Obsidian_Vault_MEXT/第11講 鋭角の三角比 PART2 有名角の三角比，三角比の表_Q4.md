# 第11講 鋭角の三角比 PART2 有名角の三角比，三角比の表 Q4

> **問題概要:** ある公園のすべり台は，次の図のように，全長が $3.8\text{ m}$，高低差が $2.0\text{ m}$ である。

[図の説明: 全長3.8m（斜辺）、高低差2.0m（高さ）の直角三角形で表されたすべり台。傾斜の角がθである。]

このすべり台の傾斜の角 $\theta$ の大きさは，およそ [ コサ ] 度である。
以下の三角比の表を用いて，最も適する整数値を求めよ。

| $\theta$ | $\sin \theta$ | $\cos \theta$ | $\tan \theta$ |
| :---: | :---: | :---: | :---: |
| $30^\circ$ | 0.5000 | 0.8660 | 0.5774 |
| $31^\circ$ | 0.5150 | 0.8572 | 0.6009 |
| $32^\circ$ | 0.5299 | 0.8480 | 0.6249 |
| $33^\circ$ | 0.5446 | 0.8387 | 0.6494 |
| $34^\circ$ | 0.5592 | 0.8290 | 0.6745 |
| $35^\circ$ | 0.5736 | 0.8192 | 0.7002 |
| $36^\circ$ | 0.5878 | 0.8090 | 0.7265 |
| $37^\circ$ | 0.6018 | 0.7986 | 0.7536 |
| $38^\circ$ | 0.6157 | 0.7880 | 0.7813 |

## 🎬 紐付けられた解説セグメント
### 📘 概念理解（前提となる基礎・解説講義）
- **🔵 パターンB** [[BL_sugaku_I_11-2-2.mp4]] (`04:17`〜`09:37`)
  - 📝 板書OCR: 例 右の図は，ある学校の階段の一部である。 この階段の傾斜の角の大きさを $\theta$ とすると $\tan \theta = \frac{18}{26} = 0.69230\dots$ 上の表より，$\tan \theta$ の値が 0.6923 に最も近い $\theta$ を求めて $\theta \fallingdotseq 35^\circ$
  - 💡 理由: 2辺の長さから三角比の値を算出し、三角比の表を参照して近似的な角度を求める原理を説明している講義であるため。
