# 第7講 2次関数とグラフ PART4 $y=a(x-p)^2+q$ のグラフ Q確認問題 1

> **問題概要:** $y=(x-2)^2+1$ のグラフの頂点は点 ( [ ア ], [ イ ] ) である。
また，グラフを次の①～③のうちから選べ。 [ ウ ]

① 頂点が $(1, 2)$ で下に凸の放物線。
② 頂点が $(2, 1)$ で下に凸の放物線。
③ 頂点が $(-2, 1)$ で下に凸の放物線。

$y=ax^2$ のグラフを
$x$ 軸方向に $p$, $y$ 軸方向に $q$
