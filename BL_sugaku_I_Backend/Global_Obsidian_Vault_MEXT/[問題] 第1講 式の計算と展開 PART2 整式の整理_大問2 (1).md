# [問題] 第1講 式の計算と展開 PART2 整式の整理_大問2 (1)

## 📝 問題文
次の整式を整理せよ。
$$x^2 + 3 - x^3 + 5x - 3x^2 - 2x^3 + 2$$

## 💡 解説・解答
[正解] $-3x^3 - 2x^2 + 5x + 5$
[解説]
$x^2 + 3 - x^3 + 5x - 3x^2 - 2x^3 + 2$
$= -x^3 - 2x^3 + x^2 - 3x^2 + 5x + 3 + 2$
$= (-1 - 2)x^3 + (1 - 3)x^2 + 5x + (3 + 2)$
$= -3x^3 - 2x^2 + 5x + 5$
