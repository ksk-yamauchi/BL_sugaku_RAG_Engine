# 第5講 集合，命題と条件 PART1 集合と要素，部分集合 Q4

> **問題概要:** $A = \{1, 2, 3, 5, 7, 11\}$，$B = \{x \mid x \text{ は } 11 \text{ 以下の素数}\}$ のとき，[ セ ] である。

[ セ ] は，次の①～③のうちから選べ。
① $A \subset B$
② $A \supset B$
③ $A = B$
