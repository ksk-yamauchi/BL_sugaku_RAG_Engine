> **【💡 解説要約】**

## 📌 スタサプ独自概要
一般の2次方程式 $ax^2 + bx + c = 0$ の左辺を平方完成して $\left(x + \dfrac{b}{2a}\right)^2 = \dfrac{b^2 - 4ac}{4a^2}$ へ変形し、平方根をとることで解の公式を論理的に導く変形操作。

## 🎬 📘 概念理解インプット講義動画
- **動画**: [[BL_sugaku_I_09-1-2.mp4]] (`02:23`〜`05:45`)
  - 📝 板書OCR: (証明)
2次方程式 $ax^2 + bx + c = 0$ …①について、①の左辺を「平方完成」すると
$ax^2 + bx + c = a(x^2 + \frac{b}{a}x) + c = a\left(x + \frac{b}{2a}\right)^2 + c - a\left(\frac{b}{2a}\right)^2 = a\left(x + \frac{b}{2a}\right)^2 - \frac{b^2 - 4ac}{4a}$
  - 💡 理由: 一般の2次方程式ax^2+bx+c=0の左辺を平方完成して2乗の形を作る変形手順を解説しているため。
- **動画**: [[BL_sugaku_I_09-1-2.mp4]] (`05:45`〜`09:04`)
  - 📝 板書OCR: となる。よって、①は
$a\left(x + \frac{b}{2a}\right)^2 - \frac{b^2 - 4ac}{4a} = 0$ すなわち $\left(x + \frac{b}{2a}\right)^2 = \frac{b^2 - 4ac}{4a^2}$
と変形できる。よって、$b^2 - 4ac \geqq 0$ のとき
$x + \frac{b}{2a} = \pm \sqrt{\frac{b^2 - 4ac}{4a^2}}$ すなわち $x = -\frac{b}{2a} \pm \frac{\sqrt{b^2 - 4ac}}{2a}$
したがって、①の解は $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$
  - 💡 理由: 平方完成した式に平方根の考え方を適用し、解の公式を論理的に導出する過程を解説しているため。
