## 📝 関連する演習問題
```text
[問題] 次の整式を整理せよ。
$$x^2 + 3 - x^3 + 5x - 3x^2 - 2x^3 + 2$$
[解説] [正解] $-3x^3 - 2x^2 + 5x + 5$
[解説]
$x^2 + 3 - x^3 + 5x - 3x^2 - 2x^3 + 2$
$= -x^3 - 2x^3 + x^2 - 3x^2 + 5x + 3 + 2$
$= (-1 - 2)x^3 + (1 - 3)x^2 + 5x + (3 + 2)$
$= -3x^3 - 2x^2 + 5x + 5$
```
```text
[問題] 次の整式を，[ ] 内の文字に着目して整理せよ。
$$2x^2 + 4xy - 5x + 3y + 7 \quad [x], [y]$$
[解説] [正解] 
$x$ に着目すると $2x^2 + (4y - 5)x + (3y + 7)$
$y$ に着目すると $(4x + 3)y + (2x^2 - 5x + 7)$
[解説]
$x$ に着目すると
$2x^2 + 4xy - 5x + 3y + 7$
$= 2x^2 + 4yx - 5x + 3y + 7$
$= 2x^2 + (4y - 5)x + (3y + 7)$

$y$ に着目すると
$2x^2 + 4xy - 5x + 3y + 7$
$= 4xy + 3y + 2x^2 - 5x + 7$
$= (4x + 3)y + (2x^2 - 5x + 7)$
```
```text
[問題] 次の整式を整理せよ。
$$5a^3 - 4 + a^2 - 7a^2 + 5a + 9$$
$$= [ア]a^3 - [イ]a^2 + 5a + [ウ]$$
[解説] [正解] ア：5，イ：6，ウ：5
[解説]
$$5a^3 - 4 + a^2 - 7a^2 + 5a + 9 = 5a^3 - 6a^2 + 5a + 5$$
文字の部分が同じ項（同類項）をまとめる。
```
```text
[問題] $A = x^2 + x + 3,\ B = 2x^2 - x - 5$ のとき、$A+B,\ A-B,\ 2A-3B$ を計算せよ。
[解説] [正解]
$A+B = 3x^2 - 2$
$A-B = -x^2 + 2x + 8$
$2A-3B = -4x^2 + 5x + 21$

[解説]
$$\begin{aligned}
A+B &= (x^2+x+3)+(2x^2-x-5) \\
&= x^2+x+3+2x^2-x-5 \\
&= 3x^2-2
\end{aligned}$$

$$\begin{aligned}
A-B &= (x^2+x+3)-(2x^2-x-5) \\
&= x^2+x+3-2x^2+x+5 \\
&= -x^2+2x+8
\end{aligned}$$

$$\begin{aligned}
2A-3B &= 2(x^2+x+3)-3(2x^2-x-5) \\
&= 2x^2+2x+6-6x^2+3x+15 \\
&= -4x^2+5x+21
\end{aligned}$$
```
```text
[問題] $A = 3x^2 + 4x - 1,\ B = x^2 - 2x - 5$ のとき、
$$A+B = 4x^2 + [ア]x - [イ]$$
[解説] [正解] ア：2，イ：6

[解説]
$$\begin{aligned}
A+B &= (3x^2+4x-1)+(x^2-2x-5) \\
&= 3x^2+4x-1+x^2-2x-5 \\
&= 4x^2+2x-6
\end{aligned}$$
加法は，そのまま括弧をはずす。その後，同類項をまとめる。
```
```text
[問題] $A = 3x^2 + 4x - 1,\ B = x^2 - 2x - 5$ のとき、
$$A-B = [ウ]x^2 + [エ]x + [オ]$$
[解説] [正解] ウ：2，エ：6，オ：4

[解説]
$$\begin{aligned}
A-B &= (3x^2+4x-1)-(x^2-2x-5) \\
&= 3x^2+4x-1-x^2+2x+5 \\
&= 2x^2+6x+4
\end{aligned}$$
減法は，引く式の各項の係数の符号をすべて変えて括弧をはずす。その後，同類項をまとめる。
```
```text
[問題] $A = 3x^2 + 4x - 1,\ B = x^2 - 2x - 5$ のとき、
$$3A-2B = [カ]x^2 + [キク]x + [ケ]$$
[解説] [正解] カ：7，キク：16，ケ：7

[解説]
$$\begin{aligned}
3A-2B &= 3(3x^2+4x-1)-2(x^2-2x-5) \\
&= 9x^2+12x-3-2x^2+4x+10 \\
&= 7x^2+16x+7
\end{aligned}$$
括弧をつけて，$A, B$ を代入し，括弧をはずし，同類項をまとめる。
```
