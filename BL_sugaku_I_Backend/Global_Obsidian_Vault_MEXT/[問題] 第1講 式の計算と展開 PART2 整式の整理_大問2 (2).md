# [問題] 第1講 式の計算と展開 PART2 整式の整理_大問2 (2)

## 📝 問題文
次の整式を，[ ] 内の文字に着目して整理せよ。
$$2x^2 + 4xy - 5x + 3y + 7 \quad [x], [y]$$

## 💡 解説・解答
[正解] 
$x$ に着目すると $2x^2 + (4y - 5)x + (3y + 7)$
$y$ に着目すると $(4x + 3)y + (2x^2 - 5x + 7)$

[解説]
$x$ に着目すると
$2x^2 + 4xy - 5x + 3y + 7$
$= 2x^2 + 4yx - 5x + 3y + 7$
$= 2x^2 + (4y - 5)x + (3y + 7)$

$y$ に着目すると
$2x^2 + 4xy - 5x + 3y + 7$
$= 4xy + 3y + 2x^2 - 5x + 7$
$= (4x + 3)y + (2x^2 - 5x + 7)$
