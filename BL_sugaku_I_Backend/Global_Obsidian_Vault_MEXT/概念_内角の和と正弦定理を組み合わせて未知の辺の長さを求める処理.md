# 概念(アクション): 内角の和と正弦定理を組み合わせて未知の辺の長さを求める処理

> **【公式テキスト】**
> (ｳ) 正弦定理や余弦定理について三角形の決定条件や三平方の定理と関連付けて理解し，三角形の辺の長さや角の大きさなどを求めること。

> **【💡 解説要約】**
> 正弦定理・余弦定理の成り立ちを三角形の決定条件や三平方の定理と紐付けて理解し、未知の辺長や角の大きさを計算する技能を身に付けさせる。

## 📌 スタサプ独自概要
2つの角と1辺が与えられたとき、三角形の内角の和 $A + B + C = 180^\circ$ から残りの角を求めた上で、正弦定理 $\dfrac{a}{\sin A} = \dfrac{b}{\sin B}$ を用いて未知の対辺の長さを算出する計算アクション。

- `三角形の内角の和`
- `特殊な角の三角比`
- `一次方程式の解法`
