# 概念(アクション): $10^n x - x$ を用いて循環小数を分数に変換する

> **【公式テキスト】**
> (ｱ) 数を実数まで拡張する意義を理解し，簡単な無理数の四則計算をすること。

> **【💡 解説要約】**
> 有理数から実数への概念拡張の意義を理解し、平方根を含む無理数の基本的な四則計算技能を習得させる。

## 📌 スタサプ独自概要
循環小数を $x$ とおき、循環部分の桁数 $n$ に合わせて $10^n x$ を作って差 $10^n x - x$ を計算することで無限小数の部分を消去し、一次方程式から既約分数へと変換する。

## ➡️ 前提知識 (重み付きネットワーク)
- **🔵 必須**: `一次方程式` (※外部概念)
  - 💡 理由: $999x = 135$ や $9x = 5$ のような一次方程式を変形して $x$ の値を求める技能が必要なため。
- **🟡 補足**: `約分` (※外部概念)
  - 💡 理由: 算出された分数を既約分数の形にするために最大公約数で割る計算が必要なため。

- **動画**: [[BL_sugaku_I_03-1-1.mp4]] (`08:31`〜`12:08`)
  - 📝 板書OCR: 例 循環小数 $0.\dot{5}1\dot{8}$ を分数で表す。 $x = 0.\dot{5}1\dot{8}$ とおく。循環している部分が 3 桁なので、$10^3 x = 1000x$ を考え、$x$ との差をとると $1000x = 518.518518\dots$ $-) x = 0.518518\dots$ $999x = 518$ $x = \frac{518}{999} = \frac{14}{27}$
  - 💡 理由: 循環小数 $x = 0.\dot{5}1\dot{8}$ に対し、循環部分の桁数 $n=3$ に合わせて $1000x$ を作り、$1000x - x = 999x$ とすることで小数部分を消去して分数へ変換する手法を直接解説しているため。
