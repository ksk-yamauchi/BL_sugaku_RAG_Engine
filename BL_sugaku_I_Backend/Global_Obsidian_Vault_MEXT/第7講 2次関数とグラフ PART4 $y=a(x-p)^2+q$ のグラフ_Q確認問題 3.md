# 第7講 2次関数とグラフ PART4 $y=a(x-p)^2+q$ のグラフ Q確認問題 3

> **問題概要:** $y=\frac{1}{2}(x-3)^2-2$ のグラフの頂点は点 ( [ ク ], [ ケコ ] ) である。
また，グラフを次の①～③のうちから選べ。 [ サ ]

① 頂点が $(3, -2)$ で下に凸の放物線。
② 頂点が $(-3, -2)$ で下に凸の放物線。
③ 頂点が $(3, -2)$ で上に凸の放物線。
