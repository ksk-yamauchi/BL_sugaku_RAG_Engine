# [タスク] 整式を代入して式の値を計算する

## 📝 関連する演習問題
```text
[問題] $A = x^2 + x + 3,\ B = 2x^2 - x - 5$ のとき、$A+B,\ A-B,\ 2A-3B$ を計算せよ。
[解説] [正解]
$A+B = 3x^2 - 2$
$A-B = -x^2 + 2x + 8$
$2A-3B = -4x^2 + 5x + 21$

[解説]
$A+B = (x^2+x+3)+(2x^2-x-5) = x^2+x+3+2x^2-x-5 = 3x^2-2$
$A-B = (x^2+x+3)-(2x^2-x-5) = x^2+x+3-2x^2+x+5 = -x^2+2x+8$
$2A-3B = 2(x^2+x+3)-3(2x^2-x-5) = 2x^2+2x+6-6x^2+3x+15 = -4x^2+5x+21$
```
```text
[問題] $A = 3x^2 + 4x - 1,\ B = x^2 - 2x - 5$ のとき、$3A-2B = [カ]x^2 + [キク]x + [ケ]$
[解説] [正解]
カ：7，キク：16，ケ：7

[解説]
$3A-2B = 3(3x^2+4x-1)-2(x^2-2x-5) = 9x^2+12x-3-2x^2+4x+10 = 7x^2+16x+7$
括弧をつけて、$A, B$ を代入し，括弧をはずし，同類項をまとめる。
```
