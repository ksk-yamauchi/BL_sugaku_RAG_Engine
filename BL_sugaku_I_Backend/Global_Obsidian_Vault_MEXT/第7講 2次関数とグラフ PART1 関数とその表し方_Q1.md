# 第7講 2次関数とグラフ PART1 関数とその表し方 Q1

> **問題概要:** 縦と横の長さの和が $8 \text{ cm}$ の長方形がある。この長方形の縦の長さを $x \text{ cm}$，面積を $y \text{ cm}^2$ とすると、$y$ は $x$ の関数である。
$y$ を $x$ の式で表すと，
$$y = [\text{ ア }] x^2 + [\text{ イ }] x$$
である。
また，この関数の定義域は，
$$[\text{ ウ }] < x < [\text{ エ }]$$
である。

  - 📝 板書OCR: y = \frac{1}{2} \cdot x \cdot (12-x) = 6x - \frac{1}{2}x^2
  - 💡 理由: 和が一定の図形における面積 $y$ を $x$ の2次式として立式・展開する解法を直接解説しているため。
- **🟢 パターンA** [[BL_sugaku_I_07-1-3.mp4]] (`03:45`〜`06:49`)
  - 📝 板書OCR: 底辺，および高さはともに正より x > 0 かつ 12-x > 0 よって定義域は 0 < x < 12 したがって y = -\frac{1}{2}x^2 + 6x (0 < x < 12)
  - 💡 理由: 辺の長さが正である条件（$x > 0$ かつ $12 - x > 0$）から定義域を導出する解法を直接解説しているため。
