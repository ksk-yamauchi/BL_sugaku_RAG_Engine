# 概念(アクション): 否定を含む命題を対偶命題に変換して同値な真偽判定を行う

> **【💡 解説要約】**
> 集合の包含関係等を利用して命題の条件と結論の関係を整理し、論理的な推論に基づいて明瞭に証明・表現させる。

## 📌 スタサプ独自概要
「$x \neq 1 \Rightarrow x^2 \neq x$」のように否定記号（$\neq$ など）を含み真偽判定が難しい命題を、対偶「$x^2 = x \Rightarrow x = 1$」という肯定的な方程式の形に変換して解集合や反例を検証し、元の命題の真偽を処理する手順。

## 🎬 📘 概念理解インプット講義動画
- **動画**: [[BL_sugaku_I_06-1-2.mp4]] (`04:27`〜`07:07`)
  - 📝 板書OCR: 例 命題 『$x+y<0 \Rightarrow x<0 \text{ または } y<0$』 の真偽について
この命題の対偶は 『$x \geqq 0 \text{ かつ } y \geqq 0 \Rightarrow x+y \geqq 0$』
これは明らかに 真 である。よって、もとの命題も 真 である。
  - 💡 理由: 直接真偽判定が難しい否定や複雑な条件を含む命題を、対偶をとることで否定のない解法しやすい形に変換して判定する具体手順を講義しているため。
