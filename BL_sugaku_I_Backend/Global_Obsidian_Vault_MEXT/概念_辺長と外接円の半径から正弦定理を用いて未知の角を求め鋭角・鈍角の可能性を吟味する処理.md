# 概念(アクション): 辺長と外接円の半径から正弦定理を用いて未知の角を求め鋭角・鈍角の可能性を吟味する処理

> **【公式テキスト】**
> (ｳ) 正弦定理や余弦定理について三角形の決定条件や三平方の定理と関連付けて理解し，三角形の辺の長さや角の大きさなどを求めること。

> **【💡 解説要約】**
> 正弦定理・余弦定理の成り立ちを三角形の決定条件や三平方の定理と紐付けて理解し、未知の辺長や角の大きさを計算する技能を身に付けさせる。

## 📌 スタサプ独自概要
辺の長さ $c$ と外接円の半径 $R$ から $\sin C = \dfrac{c}{2R}$ を計算し、$0^\circ < C < 180^\circ$ の範囲において鋭角（$C < 90^\circ$）と鈍角（$C > 90^\circ$）の2つの角が存在する可能性を考慮して求める解法手順。

## ➡️ 前提知識 (重み付きネットワーク)
- `三角比の鈍角への拡張`
- `三角方程式の基礎`
