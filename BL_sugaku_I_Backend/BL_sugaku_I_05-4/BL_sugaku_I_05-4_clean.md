### 要点① 必要条件と十分条件

2つの条件 $p$, $q$ について，命題 $p \Rightarrow q$ が真であるとき，条件 $p$, $q$ を満たすもの全体の集合をそれぞれ $P$, $Q$ とすると $P \subset Q$ である。このとき，

* $p$ は $q$ であるための「十分条件」
* $q$ は $p$ であるための「必要条件」

という。

[図の説明: 全体集合 $U$ の中に集合 $Q$ があり、$Q$ の中に集合 $P$ が含まれている（$P \subset Q$）ベン図。$P$ の領域に斜線が引かれている。]

**例** $x$ を実数とするとき，命題「$x=1 \Rightarrow x^2=1$」は真である。
よって
* $x=1$ は $x^2=1$ であるための「十分条件」
* $x^2=1$ は $x=1$ であるための「必要条件」
である。

[図の説明: 全体集合の中で、$x^2=1$ を満たす集合 $\{1, -1\}$ の円の中に、$x=1$ を満たす集合 $\{1\}$ が含まれているベン図。]

2つの命題 $p \Rightarrow q$，$q \Rightarrow p$ がともに真であるとき，「$p \Leftrightarrow q$」と表し，$p$ は $q$ であるための「必要十分条件」という。このとき，$q$ は $p$ であるための必要十分条件である。
$p \Leftrightarrow q$ のとき，$p$ と $q$ は「同値」であるという。

**例** $x$ を実数とするとき「$x=0 \Rightarrow x^2=0$」，「$x^2=0 \Rightarrow x=0$」はともに真である。
よって
* $x=0$ は $x^2=0$ であるための必要十分条件
* $x^2=0$ は $x=0$ であるための必要十分条件
であり，$x=0$ と $x^2=0$ は同値である。

### 要点② 条件の否定

条件 $p$ に対して，条件「$p$ でない」を条件 $p$ の「否定」といい，$\overline{p}$ と表す。条件 $\overline{p}$ の否定 ($\overline{\overline{p}}$) は $p$ である。
条件 $\overline{p}$ を満たすもの全体の集合は，条件 $p$ を満たすもの全体の集合 $P$ の補集合 $\overline{P}$ である。

[図の説明: 全体集合 $U$ の中に集合 $P$ があり、$P$ の外側の部分（補集合 $\overline{P}$）に斜線が引かれたベン図。]

---

**例** $x$ を実数とするとき，条件「$x > 1$」の否定は「 $x \leqq 1$ 」
$x$ を整数とするとき，条件「$x$ は偶数である」の否定は「 $x$ は奇数である 」

条件 $p$, $q$ を満たすもの全体の集合をそれぞれ $P$, $Q$ とすると
* 条件「$p$ かつ $q$」を満たすもの全体の集合は $P \cap Q$
* 条件「$p$ または $q$」を満たすもの全体の集合は $P \cup Q$
である。

[図の説明: 左図：「$p$ かつ $q$」を表すベン図。全体集合 $U$ の中で円 $P$ と円 $Q$ が交わり、2つの円が重なる共通部分（$P \cap Q$）に斜線が引かれている。
右図：「$p$ または $q$」を表すベン図。全体集合 $U$ の中で円 $P$ と円 $Q$ が交わり、両方の円を合わせた和集合の領域（$P \cup Q$）全体に斜線が引かれている。]

ド・モルガンの法則により
$$\overline{P \cup Q} = \overline{P} \cap \overline{Q}, \quad \overline{P \cap Q} = \overline{P} \cup \overline{Q}$$
が成り立つことから，条件 $p$, $q$ に関して，次のことが成り立つ。

> **「$p$ かつ $q$」の否定，「$p$ または $q$」の否定**
> $\overline{p \text{ かつ } q} \Leftrightarrow \overline{p} \text{ または } \overline{q}$, $\quad \overline{p \text{ または } q} \Leftrightarrow \overline{p} \text{ かつ } \overline{q}$

**例** $x$, $y$ を実数とするとき
* 「$x=1 \text{ かつ } y=2$」の否定は「 $x \neq 1 \text{ または } y \neq 2$ 」
* 「$x > 0 \text{ または } y > 0$」の否定は「 $x \leqq 0 \text{ かつ } y \leqq 0$ 」

### 問題 4

$x$, $y$ は実数とする。次の問いに答えよ。

(1) 次の [ $\quad$ ] に「必要条件であるが十分条件ではない」「十分条件であるが必要条件ではない」「必要十分条件である」「必要条件でも十分条件でもない」のうち適切なものを入れよ。
　(i) $x=3$ は $x^2=3x$ であるための [ $\quad$ ]。
　(ii) $x \leqq 2$ は $x < 2$ であるための [ $\quad$ ]。
　(iii) $x=0$ は，$|x|=0$ であるための [ $\quad$ ]。
　(iv) $xy > 0$ は，$x+y > 0$ であるための [ $\quad$ ]。

(2) 次の条件の否定を述べよ。ただし，$x$, $y$ は実数とする。
　(i) $x$ は有理数である。
　(ii) $x=0 \text{ かつ } y=0$
　(iii) $x < 4 \text{ または } y \geqq -2$

### Point Pickup

#### 必要条件・十分条件
条件 $p$, $q$ について
* $p \Rightarrow q$ が真ならば，$p$ は $q$ であるための **十分** 条件
* $q \Rightarrow p$ が真ならば，$p$ は $q$ であるための **必要** 条件
* $p \Leftrightarrow q$ ならば，$p$ は $q$ であるための **必要十分** 条件

$p \Rightarrow q$, $q \Rightarrow p$ がともに偽ならば，$p$ は $q$ であるための **必要条件でも十分条件でもない**。

[図の説明: 上図：$p$ は十分条件。全体集合 $U$ の中の集合 $Q$ に集合 $P$ が含まれ、$P$ に斜線が引かれている。
下図：$p$ は必要条件。全体集合 $U$ の中の集合 $P$ に集合 $Q$ が含まれ、$Q$ に斜線が引かれている。]

#### 条件の否定
条件 $p$ の否定 $\overline{p}$，条件 $q$ の否定 $\overline{q}$ について
$$\overline{p \text{ かつ } q} \Leftrightarrow \overline{p} \text{ または } \overline{q}, \quad \overline{p \text{ または } q} \Leftrightarrow \overline{p} \text{ かつ } \overline{q}$$

### 解答

#### 問題 4 解答

(1)
(i) $x^2=3x$ より $x^2-3x=0 \iff x(x-3)=0 \iff x=0, 3$
* $x=3 \Rightarrow x^2=3x$ は真
* $x^2=3x \Rightarrow x=3$ は偽（反例：$x=0$）
よって，$x=3$ は $x^2=3x$ であるための**十分条件であるが必要条件ではない**。

(ii)
* $x \leqq 2 \Rightarrow x < 2$ は偽（反例：$x=2$）
* $x < 2 \Rightarrow x \leqq 2$ は真
よって，$x \leqq 2$ は $x < 2$ であるための**必要条件であるが十分条件ではない**。

(iii)
* $x=0 \Rightarrow |x|=0$ は真
* $|x|=0 \Rightarrow x=0$ は真
よって，$x=0$ は，$|x|=0$ であるための**必要十分条件である**。

(iv)
* $xy > 0 \Rightarrow x+y > 0$ は偽（反例：$x=-1, y=-2$）
* $x+y > 0 \Rightarrow xy > 0$ は偽（反例：$x=-1, y=2$）
よって，$xy > 0$ は，$x+y > 0$ であるための**必要条件でも十分条件でもない**。

(2)
(i) $x$ は無理数である
(ii) $x \neq 0 \text{ または } y \neq 0$
(iii) $x \geqq 4 \text{ かつ } y < -2$

---

#### 確認問題 解答

##### 1 [正解] ア：②
**[解説]**
$p$：「$x=2$」，$q$：「$x^2=4$」とする。
* $p \Rightarrow q$ は，真
* $q \Rightarrow p$ は，偽（反例：$x=-2$）
よって，$p$ は $q$ であるための**十分条件であるが必要条件ではない**。

##### 2 [正解] イ：①
**[解説]**
$p$：「$x < 1$」，$q$：「$2x+3 < 1$」とする。
$2x+3 < 1$ のとき，$x < -1$
* $p \Rightarrow q$ は，偽（反例：$x=0$）
* $q \Rightarrow p$ は，真
よって，$p$ は $q$ であるための**必要条件であるが十分条件ではない**。

##### 3 [正解] ウ：③
**[解説]**
$p$：「$x^2=25$」，$q$：「$|x|=5$」とする。
$x^2=25$ のとき，$x=\pm 5$。このとき，$|x|=5$ は成り立つ。
$|x|=5$ のとき，$x=\pm 5$。このとき，$x^2=25$ は成り立つ。
* $p \Rightarrow q$ は，真
* $q \Rightarrow p$ は，真
よって，$p$ は $q$ であるための**必要十分条件である**。

##### 4 [正解] エ：④
**[解説]**
$p$：「$xy < 0$」，$q$：「$x+y < 0$」とする。
* $p \Rightarrow q$ は，偽（反例：$x=2, y=-1$）
* $q \Rightarrow p$ は，偽（反例：$x=-1, y=-2$）
よって，$p$ は $q$ であるための**必要条件でも十分条件でもない**。

##### 5 [正解] オ：③
**[解説]**
「$x$ は正の数である」の否定は，「$x$ は正の数でない」
つまり，$x$ は **0 以下の数である**。

##### 6 [正解] カ：③
**[解説]**
「$x=1 \text{ かつ } y=2$」の否定は，**$x \neq 1 \text{ または } y \neq 2$**。

##### 7 [正解] キ：②
**[解説]**
「$x > 0 \text{ または } y \leqq 1$」の否定は，**$x \leqq 0 \text{ かつ } y > 1$**。
