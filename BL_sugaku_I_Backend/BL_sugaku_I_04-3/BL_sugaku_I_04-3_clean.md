# PART3 絶対値を含む方程式・不等式

## 要点① 絶対値を含む方程式・不等式

方程式 $|x| = 2$ を解く。
$|x|$ は，原点と実数 $x$ が表す点との**距離**を表す。よって，$|x| = 2$ の解は
$$x = \pm 2$$

[図の説明: 原点0を中心とし、距離2離れた点 -2 と 2 の位置に黒丸がある数直線。0から -2 へ、0から 2 へそれぞれ長さ2の距離が表されている。$|x|=2$ の解を表す。]

不等式 $|x| < 2$ の解は
$$-2 < x < 2$$

[図の説明: 数直線上で -2 から 2 までの範囲（開区間）に斜線が引かれた図。$-2 < x < 2$ を表す。]

不等式 $|x| > 2$ の解は
$$x < -2, \quad 2 < x$$

[図の説明: 数直線上で -2 より左側の範囲と、2 より右側の範囲に斜線が引かれた図。$x < -2, \quad 2 < x$ を表す。]

一般に，次のことが成り立つ。

---

### 絶対値を含む方程式・不等式
$c > 0$ のとき
* 方程式 $|x| = c$ の解は　$x = \pm c$
* 不等式 $|x| < c$ の解は　$-c < x < c$
* 不等式 $|x| > c$ の解は　$x < -c, \quad c < x$

---

#### 例
方程式 $|x+1| = 5$ を解く。
$x+1 = X$ とおくと　$|X| = 5$ より $X = \pm 5$
よって $x+1 = \pm 5$ より $x = -1 \pm 5$　　したがって $x = 4, \quad -6$

不等式 $|x+1| \leqq 5$ を解く。
$$-5 \leqq x+1 \leqq 5$$
各辺に $-1$ を加えて　$-6 \leqq x \leqq 4$

# PART3 絶対値を含む方程式・不等式 解答

**3**
(1) 次の方程式を解け。
　(i) $|x| = 3$　　(ii) $|x-1| = 3$
(2) 次の不等式を解け。
　(i) $|x| < 3$　　(ii) $|x+2| < 3$
　(iii) $|x| \geqq 3$　　(iv) $|x-3| \geqq 3$

**［解答］**
(1) (i) $|x| = 3$ より $x = \pm 3$
　(ii) $|x-1| = 3$ より $x-1 = \pm 3 \quad x = 1 \pm 3 \quad$ よって $x = 4, \quad -2$

(2) (i) $|x| < 3$ より $-3 < x < 3$
　(ii) $|x+2| < 3$ より $-3 < x+2 < 3 \quad$ よって $-5 < x < 1$
　(iii) $|x| \geqq 3$ より $x \leqq -3, \quad 3 \leqq x$
　(iv) $|x-3| \geqq 3$ より $x-3 \leqq -3, \quad 3 \leqq x-3 \quad$ よって $x \leqq 0, \quad 6 \leqq x$

# 第 4 講 PART3 確認問題 解答

**1** ［正解］ア：2
［解説］
$|x| = 2$ の解は，【A】
$$x = \pm 2$$
【A】$c > 0$ のとき，$|x| = c$ の解は，$x = \pm c$

**2** ［正解］イ：3，ウエ：$-7$
［解説］
$|x+2| = 5$ の解は，
$$x+2 = \pm 5 \quad \text{【B】}$$
$$x = -2 \pm 5$$
$$x = -7, \quad 3$$
【B】$x+2 = X$ とおくと，$|X| = 5$ より，$X = \pm 5$

**3** ［正解］オカ：$-4$，キ：4
［解説］
$|x| < 4$ の解は，【C】
$$-4 < x < 4$$
【C】$c > 0$ のとき，$|x| < c$ の解は，$-c < x < c$

**4** ［正解］クケ：$-1$，コ：5
［解説］
$|x-2| < 3$ の解は，【D】
$$-3 < x-2 < 3$$
$$2-3 < x < 2+3 \quad \text{【E】}$$
$$-1 < x < 5$$
【D】$x-2 = X$ とおくと，$|X| < 3$ より，$-3 < X < 3$
【E】各辺に 2 を加える。

**5** ［正解］サシ：$-5$，ス：5
［解説］
$|x| \geqq 5$ の解は，【F】
$$x \leqq -5, \quad 5 \leqq x$$
【F】$c > 0$ のとき，$|x| \geqq c$ の解は，$x \leqq -c, \quad c \leqq x$

**6** ［正解］セ：1，ソ：5
［解説］
$|x-3| \geqq 2$ の解は，【G】
$$x-3 \leqq -2, \quad 2 \leqq x-3$$
$$x \leqq 1, \quad 5 \leqq x$$
【G】$x-3 = X$ とおくと，$|X| \geqq 2$ より，$X \leqq -2, \quad 2 \leqq X$
