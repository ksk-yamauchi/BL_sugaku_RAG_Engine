# PART3 $y=ax^2+q$ のグラフ，$y=a(x-p)^2$ のグラフ

## 要点① $y=ax^2$ のグラフ

$y=x^2$, $y=-2x^2+3x-4$ のように、$y$ が $x$ を用いて
$$(a, b, c \text{ は定数}, a \neq 0)$$
の形で表されるとき、$y$ は $x$ の「 [ 2次関数 ] 」という。

2次関数 $y=ax^2$ のグラフは、原点を通り $y$ 軸に関して対称な [ 放物線 ] である。例えば、2次関数 $y=x^2$ のグラフは、右図のような放物線である。

[図の説明: 頂点が原点 $O(0,0)$ で下に凸の放物線 $y=x^2$ のグラフ。点 $(1,1)$, $(2,4)$, $(-1,1)$, $(-2,4)$ を通る。]

放物線の対称の軸を、単に「 [ 軸 ] 」という。また、軸と放物線の交点を「 [ 頂点 ] 」という。2次関数 $y=ax^2$ のグラフの軸は [ $y$ 軸（直線 $x=0$） ]、頂点は点 [ $(0, 0)$ ] である。

また、2次関数 $y=ax^2$ のグラフは、その放物線の形から
* $a>0$ のとき「 [ 下に凸 ] 」
* $a<0$ のとき「 [ 上に凸 ] 」

であるという。

[図の説明: 左側は $a>0$ の場合のグラフ。原点を頂点とし下に凸の放物線で、$x<0$ で減少、$x>0$ で増加する。「下に凸」と表記。右側は $a<0$ の場合のグラフ。原点を頂点とし上に凸の放物線で、$x<0$ で増加、$x>0$ で減少する。「上に凸」と表記。]

---

## 要点② 平行移動と $y=ax^2+q$ のグラフ

* 「 [ 平行移動 ] 」… 平面上で、図形上の各点を一定の向きに一定の距離だけ移動させること。移動によって図形の形や向きは変わらない。
* 「 [ $x$ 軸方向に平行移動 ] 」… $x$ 軸の正の向き
* 「 [ $y$ 軸方向に平行移動 ] 」… $y$ 軸の正の向き

**例** $y=x+1$ のグラフは、$y=x$ のグラフを [ $y$ 軸方向 ] に [ $1$ ] だけ [ 平行移動 ] した直線である。

[図の説明: 座標平面上に直線 $y=x$（破線）と、$y$ 軸正の方向に $1$ だけ平行移動した直線 $y=x+1$（実線）が描かれている。]

$x$ の各値において、$y=x^2+1$ の $y$ の値は、$y=x^2$ より $1$ だけ大きい。
よって、$y=x^2+1$ のグラフは、$y=x^2$ のグラフを [ $y$ 軸方向 ] に [ $1$ ] だけ [ 平行移動 ] した放物線である。また、グラフの軸は [ $y$ 軸 ]、頂点は点 [ $(0, 1)$ ] である。

一般に、次のことがいえる。

[図の説明: 放物線 $y=x^2$（破線、頂点 $(0,0)$）と、$y$ 軸方向に $+1$ だけ平行移動した放物線 $y=x^2+1$（実線、頂点 $(0,1)$）が描かれている。]

### 2次関数 $y=ax^2+q$ のグラフ
2次関数 $y=ax^2+q$ のグラフは、$y=ax^2$ のグラフを $y$ 軸方向に $q$ だけ平行移動した放物線であり、グラフの軸は $y$ 軸、頂点は点 $(0, q)$ である。

---

## 要点③ $y=a(x-p)^2$ のグラフ

$y=(x-1)^2$ のグラフについて考える。$y=(x-1)^2$ は、$y=x^2$ の $x$ を $x-1$ におき換えた式である。ここで、$x$ の各値に対する関数 $y=x^2$, $y=(x-1)^2$ の値を比べる。

| $x$ | $\dots$ | $-2$ | $-1$ | $0$ | $1$ | $2$ | $\dots$ |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| $x^2$ | $\dots$ | $4$ | $1$ | $0$ | $1$ | $4$ | $\dots$ |
| $(x-1)^2$ | $\dots$ | $9$ | $4$ | $1$ | $0$ | $1$ | $\dots$ |

この表により、同じ $y$ の値をとる $x$ が、[ $1$ ] だけ [ 右（$x$軸の正の方向） ] にずれていることがわかる。これは他の $x$ の値でも同様である。

よって、$y=(x-1)^2$ のグラフは、$y=x^2$ のグラフを [ $x$ 軸方向 ] に [ $1$ ] だけ [ 平行移動 ] した放物線である。また、グラフの軸は [ 直線 $x=1$ ]、頂点は点 [ $(1, 0)$ ] である。

[図の説明: 放物線 $y=x^2$（破線、頂点 $(0,0)$）と、$x$ 軸方向に $+1$ だけ平行移動した放物線 $y=(x-1)^2$（実線、頂点 $(1,0)$）が並べて描かれている。]

一般に、次のことがいえる。

### 2次関数 $y=a(x-p)^2$ のグラフ
2次関数 $y=a(x-p)^2$ のグラフは、$y=ax^2$ のグラフを $x$ 軸方向に $p$ だけ平行移動した放物線であり、グラフの軸は直線 $x=p$、頂点は点 $(p, 0)$ である。
