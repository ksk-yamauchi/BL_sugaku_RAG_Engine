# 第15講 データの分析
## PART1 データの整理と代表値

### 要点① データの整理

* 「変量」… 身長，気温，テストの点数の用に，人や物の特性を数量的に表すもの
* 「データ」… 変量の観測値や測定値などの集まり

データを整理する方法として，「度数分布表」や「ヒストグラム」がある。

#### 例
次のデータは，あるクラスの生徒 10 人のハンドボール投げ (m) の結果である。

$$13,\ 21,\ 15,\ 18,\ 18,\ 16,\ 17,\ 15,\ 19,\ 18 \text{ (m)}$$

**度数分布表**

| 階級 (m) | 度数 (人) |
| :--- | :--- |
| 12 以上 14 未満 | |
| 14 ～ 16 | |
| 16 ～ 18 | |
| 18 ～ 20 | |
| 20 ～ 22 | |
| 計 | 10 |

**ヒストグラム**

[図の説明: 横軸に階級(m) 12, 14, 16, 18, 20, 22、縦軸に度数（人）0〜5をとったヒストグラム。12以上14未満が1、14以上16未満が2、16以上18未満が2、18以上20未満が4、20以上22未満が1の高さの長方形が描かれている。]

* 階級の幅は [ $\quad$ ] m
* 14 m 以上 16 m 未満の階級の相対度数は $\frac{[\quad]}{10} = 0.2$

---

### 要点② データの代表値

「代表値」… データ全体の特徴を 1 つの数値で表したもの
主な代表値として「 [ $\quad$ ] 」「 [ $\quad$ ] 」「 [ $\quad$ ] 」がある。

「平均値」… 変量 $x$ についてのデータが，$n$ 個の値 $x_1,\ x_2,\ \dots,\ x_n$ であるとき，これらの和を値の個数 $n$ で割ったもの。「 [ $\quad$ ] 」で表す。

$$\bar{x} = \frac{1}{n}(x_1 + x_2 + \cdots + x_n)$$

---

「中央値」… データを値の大きさの順（小さい順，大きい順）に並べたとき，中央の位置にくる値。メジアンともいう。
データの個数が偶数のときは，中央に並ぶ 2 つの値の平均値。

「最頻値」… データにおいて，最も個数の多い値。モードともいう。
データが度数分布表に整理されているときは，度数が最も大きい階級の階級値（階級の中央の値）を最頻値とする。

#### 例
データ

$$13,\ 21,\ 15,\ 18,\ 18,\ 16,\ 17,\ 15,\ 19,\ 18 \text{ (m)}$$

について，代表値を求める。

このデータの平均値は
$$\bar{x} = \frac{170}{10} = 17.0 \text{ (m)}$$

このデータを小さい順に並べると
$$13,\ 15,\ 15,\ 16,\ 17,\ 18,\ 18,\ 18,\ 19,\ 21$$

よって，このデータの中央値は $= 17.5 \text{ (m)}$

このデータの最頻値は [ $\quad$ ] m

※右表のように，度数分布表に整理されているとき，
最頻値は $= 19 \text{ (m)}$

＜度数分布表＞

| 階級 (m) | 度数 (人) |
| :--- | :--- |
| 12 以上 14 未満 | 1 |
| 14 ～ 16 | 2 |
| 16 ～ 18 | 2 |
| 18 ～ 20 | 4 |
| 20 ～ 22 | 1 |
| 計 | 10 |

平均値は極端に離れた値の影響を受けやすく，中央値は極端に離れた値の影響を受けにくい。

### Point Pickup
**代表値（平均値，最頻値，中央値）**

* **平均値** $\dots \bar{x} = \frac{1}{n}(x_1 + x_2 + \cdots + x_n)$
  * 平均値は，極端に離れた値の影響を受けやすい
* **最頻値** $\dots$ 最も個数の多い値。
  * 度数分布表に整理されているときは，度数が最も大きい階級の階級値。
* **中央値** $\dots$ 大きさの順に並べたとき，中央の位置にくる値。
  * データの個数が偶数のときは，中央に並ぶ 2 つの値の平均値。
  * 中央値は，極端に離れた値の影響を受けにくい。

## 解答・解説

### 1 (演習問題)
**(1)**
- **(i)**
  - 平均値は $\frac{32 + 40 + 31 + 45 + 80}{5} = \frac{228}{5} = 45.6$
  - データを小さい順に並べると 31，32，40，45，80
  - よって，中央値は **40**
- **(ii)**
  - 平均値は $\frac{45 + 41 + 39 + 50 + 44 + 45}{6} = \frac{264}{6} = 44$
  - データを小さい順に並べると 39，41，44，45，45，50
  - よって，中央値は $\frac{44 + 45}{2} = \mathbf{44.5}$

**(2)**
- **(i)** 度数の合計が 27 人より，中央値は値の小さい方から（大きい方から）14 番目の値である。これが含まれる階級は **16 m 以上 18 m 未満**
- **(ii)** 度数が最も大きい階級は 16 m 以上 18 m 未満。よって，最頻値は $\frac{16 + 18}{2} = \mathbf{17 \text{ (m)}}$

### 確認問題 解答

#### 1
**［正解］** ア：6  
**［解説］**

$$\frac{1 + 2 + 4 + 5 + 5 + 8 + 10 + 13}{8} = \frac{48}{8} = 6$$

#### 2
**［正解］** イ：8，ウ：9  
**［解説］**  
- (A) データが 7 個だから，値の小さい方から 4 番目にくる値が中央値になる。
  中央値は，**8**
- (B) データが 8 個だから，小さい方から 4 番目と 5 番目にくる値の平均が中央値となる。
  中央値は，$\frac{7 + 11}{2} = \mathbf{9}$

#### 3

**［解説］**
