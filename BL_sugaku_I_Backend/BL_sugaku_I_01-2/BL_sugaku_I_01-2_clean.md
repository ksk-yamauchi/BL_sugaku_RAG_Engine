# PART2 整式の整理

**2**
(1) 次の整式を整理せよ。
$$x^2 + 3 - x^3 + 5x - 3x^2 - 2x^3 + 2$$

(2) 次の整式を，[ ] 内の文字に着目して整理せよ。
$$2x^2 + 4xy - 5x + 3y + 7 \quad [x], [y]$$

［解答］
(1) $x^2 + 3 - x^3 + 5x - 3x^2 - 2x^3 + 2$
$$= -x^3 - 2x^3 + x^2 - 3x^2 + 5x + 3 + 2$$
$$= (-1 - 2)x^3 + (1 - 3)x^2 + 5x + (3 + 2)$$
$$= -3x^3 - 2x^2 + 5x + 5$$

(2) $x$ に着目すると
$$2x^2 + 4xy - 5x + 3y + 7$$
$$= 2x^2 + 4yx - 5x + 3y + 7$$
$$= 2x^2 + (4y - 5)x + (3y + 7)$$

$y$ に着目すると
$$2x^2 + 4xy - 5x + 3y + 7$$
$$= 4xy + 3y + 2x^2 - 5x + 7$$
$$= (4x + 3)y + (2x^2 - 5x + 7)$$

**1** ［正解］ア：5，イ：6，ウ：5

[図の説明: 数式 $5a^3 - 4 + a^2 - 7a^2 + 5a + 9$ において、定数項「$-4$」と「$+9$」、$a^2$ の項「$+a^2$」と「$-7a^2$」がそれぞれ「同類項」として下線・下枠で結ばれている図。]

**2** ［正解］エ：②

［解説］
[図の説明: 整式 $x^3 + 3xy + 4y^2 - 2x + 7y - 8$ の中で、$3xy$ と $-2x$ をまとめて $x$ の項とし、$4y^2$ と $+7y$ と $-8$ をそれぞれ定数項として分類している図。]

$$x^3 + 3xy + 4y^2 - 2x + 7y - 8$$
$$= x^3 + (3y - 2)x + 4y^2 + 7y - 8$$

［Ｂ］ 「$x$ について」と指示があるので，$y$ は定数とみなす。

**3** ［正解］オ：③

［解説］
[図の説明: 整式 $x^3 + 3xy + 4y^2 - 2x + 7y - 8$ の中で、$4y^2$ を $y^2$ の項、$3xy$ と $+7y$ をまとめて $y$ の項とし、$x^3$、$-2x$、$-8$ をそれぞれ定数項として分類している図。]

$$x^3 + 3xy + 4y^2 - 2x + 7y - 8$$
$$= 4y^2 + (3x + 7)y + x^3 - 2x - 8$$

［Ｃ］ 「$y$ について」と指示があるので，$x$ は定数とみなす。
