# PART2 1次関数のグラフと最大値，最小値

## 要点① 座標平面

平面上に，右図のように原点 $\text{O}$ で直交する2つの数直線を座標軸 $x$ 軸，$y$ 軸として定めると，その平面上の点 $\text{P}$ の位置は，2つの実数の組 $(a, b)$ で表される。この組 $(a, b)$ を，点 $\text{P}$ の「 [ 座標 ] 」といい，$\text{P}(a, b)$ と表す。また，このときの $a$ を $x$ 座標，$b$ を $y$ 座標という。

[図の説明: $x$軸と$y$軸が原点$\text{O}$で直交する座標平面。点$\text{P}(a, b)$から$x$軸に下ろした垂線の足が$a$、$y$軸に下ろした垂線の足が$b$と示されている。]

座標軸の定められた平面を「座標平面」という。座標平面は，座標軸によって4つの部分に分けられ，右図のように「 [ 第1象限 ] 」「 第2象限 」「 第3象限 」「 第4象限 」という。
座標軸上の点は，どの象限にも含まれないものとする。

[図の説明: 座標平面が$x$軸・$y$軸で4つの領域に分けられている図。右上が「第1象限」、左上が「第2象限」、左下が「第3象限」、右下が「第4象限」と配置されている。]

## 要点② 関数のグラフ

関数 $y = f(x)$ において，$y = f(x)$ を満たすような点 $(x, y)$ 全体で作られる図形を，この関数の「 [ グラフ ] 」という。
例えば，関数 $y = 2x - 1$ のグラフは，右図のようにこの式を満たす点全体からなる図形である。

[図の説明: 傾きが正の直線 $y = 2x - 1$ のグラフ。$y$軸の切片が $-1$、$x$軸との交点が $\left(\frac{1}{2}, 0\right)$ を通る直線。]

$y = 2x - 1$，$y = -3x$ のように，$y$ が $x$ を用いて
$$y = ax + b \quad (a, b \text{ は定数}, a \neq 0)$$
の形で表されるとき，$y$ は $x$ の「 [ 1次関数 ] 」という。
1次関数 $y = ax + b$ のグラフは，傾き $a$，切片が $b$ の [ 直線 ] である。

- $a > 0$ のとき
  [図の説明: 傾き $a > 0$（右上がり）の直線 $y = ax + b$。$y$軸の切片 $b$ から$x$方向に$1$進むと$y$方向に$a$増加することを示す矢印が描かれている。$x$の増加にともない$y$が増加する。]

- $a < 0$ のとき
  [図の説明: 傾き $a < 0$（右下がり）の直線 $y = ax + b$。$y$軸の切片 $b$ から$x$方向に$1$進むと$y$方向に$a$減少することを示す矢印が描かれている。$x$の増加にともない$y$が減少する。]

## 要点③ 関数の最大値・最小値

関数の値域に最大の値があるとき，その値をこの関数の「 [ 最大値 ] 」といい，最小の値があるとき，その値をこの関数の「 [ 最小値 ] 」という。

**[例]** 関数 $y = -x + 2 \quad (1 \leqq x < 3)$ の最大値，最小値について
関数 $y = -x + 2$ のグラフは，傾き $-1$，切片 $2$ の直線
関数 $y = -x + 2$ において
- $x = 1$ のとき $y = 1$
- $x = 3$ のとき $y = -1$

よって，グラフは右図実線部分。
したがって，この関数は
$x = 1$ で [ 最大値 1 ] をとる。
また， [ 最小値はない ] 。

[図の説明: 1次関数 $y = -x + 2$ のグラフ。定義域 $1 \leqq x < 3$ に対応する部分が実線で描かれている。点 $(1, 1)$ は黒丸（端点を含む）、点 $(3, -1)$ は白丸（端点を含まない）で示されており、範囲外は破線で描かれている。]

## Point Pickup

### 座標平面と象限
座標平面は，座標軸によって4つの部分に分けられ，右図のように「第1象限」「第2象限」「第3象限」「第4象限」という。
※座標軸上の点は，どの象限にも含まれない。

[図の説明: 座標平面。原点$\text{O}$を中心に、右上＝第1象限、左上＝第2象限、左下＝第3象限、右下＝第4象限の位置関係を示す図。]

### 1次関数の最大値，最小値
1次関数のグラフは直線である。傾きや切片に注目してグラフをかく。
定義域の端の点（端点）に注目し，端点がグラフに含まれる場合は，その点が最大または最小の候補となる（1次関数の場合は，最大または最小になる）。

### 3
